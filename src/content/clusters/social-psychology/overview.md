社會與心理學群（簡稱社心學群）研究的核心始終是「人」與「社會」。這份風向標協助你在出發前看清整個學群的地形：它是什麼、內部如何分流、有哪些校系、以及 2026 年的申請風向往哪裡吹。

> 本頁以 **2026 年、即 115 學年度** 大學個人申請現況為準。

## 一、學群定位：從「履歷清單」到「個人代表作」

當前大學個人申請的審查核心，已經歷一場深刻的典範轉移。審查委員不再只是檢閱一份「活動清單」，而是在尋找能代表你個人特質與思維深度的「代表作」。

大學招生委員會聯合會（招聯會）持續強調，備審資料採 **「綜合性評量」而非「集點積分式評分」**，審查重心以校內學習活動為主。各校系於 2026 年初公布的最新「審查資料準備指引」，也一致重申「重質不重量」、「作品在精不在多」。

| 舊思維 | 2026 的審查風向 |
| :---- | :---- |
| 比時數、比數量、集點 | 比反思品質、比洞察深度 |
| 呈現完美無瑕的成果 | 誠實記錄歷程、限制與失敗中的學習 |
| 羅列彼此無關的活動 | 用一條「黃金線索」串成連貫故事 |

這個學群最核心的思維能力，是社會學家米爾斯（C. Wright Mills）所說的 **「社會學的想像力」**——能把個人的、微觀的「生活煩惱」（家庭溝通問題、對在地市場的觀察），連結到宏觀的、結構性的「公共議題」（世代價值觀衝突、都市的非正式經濟）。你的整份申請資料，就是這場想像力的實踐展演。

## 二、社會學 vs. 心理學：學群內部的分流

社心學群橫跨「人文社會關懷」與「科學實證」兩種精神。理解這條分流線，是選系的第一步。

| 面向 | 社會學取向（社會學系／社工系） | 心理學取向（心理學系） |
| :---- | :---- | :---- |
| 分析焦點 | 宏觀：社會趨勢、制度、權力關係、不平等 | 微觀：個體行為、心智歷程、發展與異常 |
| 同理心側重 | 關注苦難的**系統性成因**，對**集體**的同理 | 關注苦難的**個體經驗**，對**個人**的同理 |
| 知識性格 | 社會理論、歷史變遷、政策分析、質性研究 | 認知神經科學、發展心理學、量化與實驗方法 |
| 學科本質 | 社會關懷與結構性批判 | 一門嚴謹的**實證科學**，兼具人文關懷 |

- **社會學系／社會工作學系**：重視批判性思考、社會關懷與結構性分析。社工系核心是「助人專業」，更看重人格特質、同理心與社會覺察力。
- **心理學系**：是一門橫跨自然科學與人文社會的學科，理想申請者需同時展現「科學的嚴謹」與「人文的關懷」。請務必認知到心理學不等於哲學、算命或讀心術。

## 三、校系地圖：指標性系所與選才理念

不同學校在官方文件中明確揭示了所尋找的學生特質。這是你校準準備方向最權威的依據（核心能力定義自 113 至 115 學年度保持穩定）。

| 大學與科系 | 官方核心能力／選才理念 |
| :---- | :---- |
| 臺灣大學 社會學系 | 溝通領導、批判思考、主動學習、合作共榮 |
| 政治大學 社會學系 | 自發問題分析、社會關懷共好、溝通合作互動、自我認知探索 |
| 政治大學 心理學系 | 觀察與自省能力、對心理學的真實興趣、科學嚴謹性 |
| 清華大學 人社院學士班 | 正面影響他人、解決衝突、對團體有貢獻 |
| 亞洲大學 社工系／心理系 | 同理心、團隊合作、助人能力、心得反思 |

延伸資源可查詢 **ColleGo!** 選才育才輔助系統的「社會心理學群」頁面，了解各科系的完整介紹與選才取向。

## 四、2026 趨勢與重要時程

- **趨勢一：學科是「活的實踐」。** 由台灣社會學會支持的科普平台《巷仔口社會學》至 2026 年仍持續高頻發表文章，緊扣台灣社會脈動；台灣社會學會 2026 年年會主題為「抵抗與團結：為動盪世界而生的社會學」。學科關懷始終扣連時代、回應現實。
- **趨勢二：當代議題提供豐富素材。** 2024 年的「青鳥行動」與延伸至 2025 年的「大罷免」（32 案罷免全數未通過），是觀察台灣民主、世代政治參與、社群媒體動員的鮮活案例；生成式 AI 的普及則讓「數位落差」「演算法同溫層」更具當代性。
- **趨勢三：心理健康成為政策焦點。** 衛福部自 2023 年起推動相關方案，2026 年（115 年度）持續以「15–45 歲青壯世代心理健康支持方案」加碼辦理，投入約 3.5 億元經費，提供每人 3 次免費心理諮商。
