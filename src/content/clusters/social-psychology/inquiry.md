# 社會與心理學群：自主學習與探究專題方向

「自主學習計畫與成果」是 108 課綱下最具鑑別度的環節，也是直接證明你內在學習動機的項目。大學招生委員會尋找的不是已然成熟的學者，而是一位 **「準學者」**——展現好奇心、能提出有意義的探問、選擇合適的研究途徑，並對過程與結果深刻反思的年輕心靈。

## 一、洞察力的養成：從個人煩惱到公共議題

具備洞察力的探究，其底層結構往往遵循「問題—介入—反思」（Problem-Intervention-Reflection）模型：

1. **問題**：在個人經驗中識別出一個矛盾、疑問或認知失調的時刻（個人的煩惱）。
2. **介入**：採取行動——可以是知識層面（研究某議題）、實踐層面（加入相關社團）或互動層面（人物訪談）。
3. **反思**：分析介入的結果，把新理解連結回更大的社會或心理學原則（公共議題）。

一個強大的敘事引擎是心理學家費斯汀格的「認知失調」理論：例如「我對社會平等的信念」與「觀察到家中長輩面臨數位落差的現實」之間的矛盾，整篇探究便可圍繞如何化解這種失調展開。

把個人經驗連結到學術概念，並非為了賣弄名詞，而是為了提供分析工具。常用概念：

- **社會學概念**：社會階層化、社會流動、性別角色、社會不平等（數位落差）、社會制度功能。
- **心理學概念**：認知失調、認同形成、內團體／外團體動力、情緒智商、心理健康理論典範。

## 二、社會學導向的熱門探究主題

| 主題領域 | 可探究的關鍵問題 | 參考素材範例 |
| :---- | :---- | :---- |
| **性別與認同** | 大眾媒體如何強化或挑戰傳統的陽剛氣質？ | 電影《82 年生的金智英》、吳嘉苓教授對人工生殖的研究 |
| **社會不平等** | 哪些結構性因素導致青年世代的經濟無望感？ | 〈階級凝視下的魯蛇人生〉、不同階級的教養模式比較 |
| **歷史與政治** | 歷史事件如何透過不同媒介被再現與詮釋？ | 小說《傀儡花》、何明修教授對社會運動的分析 |
| **邊緣群體** | 社會制度如何對特定群體造成系統性歧視？ | 〈在巷仔口碰見「街友」〉、藍佩嘉教授的移工研究 |

> **策略提示**：《巷仔口社會學》這類由大學教授為大眾撰寫的普及讀物，其涵蓋議題與成功學生專題高度重疊——這些作者往往就是未來審查你資料的教授。閱讀他們為公眾寫的書，等於進入一場既有的學術對話。台灣近年「青鳥行動」「大罷免」也提供了具當代性的社會運動探究素材。

## 三、心理學導向的熱門探究主題

- **導航自我**：青少年心理健康（憂鬱、焦慮）、壓力管理、情緒智商、自尊、幸福感的科學。可做正念減壓技術的文獻回顧。**衛福部「15–45 歲青壯世代心理健康支持方案」（2026 年加碼至約 3.5 億元、每人 3 次免費諮商）** 本身就是極佳題材——「3 次免費諮商是否足夠」「如何讓求助去汙名化」兼具個人關懷與政策分析。
- **發展中的心靈**：兒童早期發展、學習理論、兒童認知偏誤、青少年認同形成。常與幼兒園志工、輔導室實習等實踐經驗結合。
- **社會中的心靈**：社會認知、人際關係、群體動力、從眾行為、偏見、溝通心理學——這是心理學與社會學的交集。

**掌握「從個人到學術的轉軸」**：最引人注目的心理學專題以個人經驗為「動機」，但以學術框架與證據進行「分析」。敘事結構：「我對於 X 的經驗，引發我對心理學原理的好奇。為了探究，我閱讀了某本書、學習到某理論，這幫助我以全新、更結構化的方式理解最初的經驗。」

## 四、學者的工具箱：研究方法比較

| 研究方法 | 簡要描述 | 在申請資料中的優勢 | 常見陷阱與避免方式 |
| :---- | :---- | :---- | :---- |
| **文獻與媒介分析** | 批判性閱讀、比較、綜合多種來源 | 展現資訊綜合與建構論點的能力 | 勿只做摘要——要提出觀點、比較異同 |
| **結構式訪談** | 對少數受訪者進行標準化提問 | 展現同理心、傾聽與質性資料蒐集 | 避免誘導性問題、遵守訪談倫理 |
| **問卷調查** | 對小規模樣本調查特定態度或行為 | 展現邏輯思維與量化方法初步理解 | 誠實討論樣本限制、先找同學試填修正 |
| **田野觀察** | 在特定社會場域系統性觀察記錄 | 展現觀察力、社會關懷與情境理解 | 區分「觀察到的事實」與「個人詮釋」 |

文獻與媒介分析最易上手，門檻在於超越讀書報告——以《傀儡花》專題為例，學生交叉比對歷史課本、紀錄片與地圖，進行多重來源的批判性綜合。

## 五、研究的「過程」即是「成果」

招生委員對學生的探究旅程，包括其中遭遇的困難，抱有高度興趣。一份誠實記錄限制（「我最初設計的問卷帶有偏見，因此重新設計」）的專題，遠比一份完美無瑕的報告更令人信服。

建議在 **「研究日誌」** 中鉅細靡遺記錄整個探究過程，作為最終反思報告的原始材料，敘說一個關於智識成長、解決問題與韌性的故事。

### 自我檢視清單

- **問題設定**：我的問題是否超越「是什麼」，進入「為什麼」或「如何」的層次？
- **方法選擇**：研究方法是否適合我的問題？我是否清楚其優點與限制？
- **倫理考量**：是否考慮了保護受訪者隱私等倫理議題？
- **反思深度**：我能否清晰闡述從錯誤中學到什麼？
- **價值連結**：這份專題如何證明我具備目標校系尋找的特質？
