備審資料與面試的核心目標一致：向審查教授證明你不只是一個有潛力的學生，更是一個準備好為這個學術社群帶來獨特貢獻的未來學者。本頁帶你把前面累積的特質與作品，編織成有說服力的申請敘事。

> 本頁以 **2026 年、即 115 學年度** 個人申請現況為準。

## 一、敘事的黃金線索

一份卓越的檔案，其所有部分——修課紀錄、自主學習、多元表現——都應相互佐證，共同指向一個清晰的核心動機。你需要找到一條貫穿始終的「黃金線索」，把個人生命經驗、智識好奇心的萌芽、主動探究的行動，以及對未來的學術想望串成一個令人信服的成長故事。

學習歷程檔案是一份**連貫的論證，而非剪貼簿**。若你在自述中宣稱具備「批判思考」，但自主學習成果只是淺薄的資料摘要，就構成矛盾。

## 二、學習歷程自述：四大段落撰寫指南

政治大學社會學系提供的書審準備指引結構完整，可作為所有申請者構思個人陳述的通用模板。

| 段落 | 撰寫重點 |
| :---- | :---- |
| **就讀動機** | 闡述你的「為何而來」故事。把個人經歷與價值觀，連結到所申請科系的特定精神。動機要源於真實經歷與深刻反思，而非編造教授會喜歡聽的故事。 |
| **學習歷程反思** | 展示批判思考與科學探究特質的最佳場域。不要羅列修過的課，而要說明「哪一門課啟發了你」「你如何延伸這份興趣」。 |
| **多元表現綜整心得** | 證明社會關懷與協作能力的機會。選一至兩項最具代表性的活動深入闡述，重點不是頭銜，而是你的角色、行動與反思。 |
| **未來學習計畫與生涯規劃** | 展現對科系的深入了解與真誠投入。需事先研究該系課程地圖、師資專長與研究方向，計畫要具體、個人化（例如對某位教授的研究領域特別感興趣）。 |

撰寫敘事弧線可圍繞：**動機（火花）→ 過程（旅程）→ 發現（成果）→ 反思（成長）**，最後明確連結目標校系的核心素養。

## 三、面試策略：把書面形象立體化

面試不只是問答，更是一場檢驗你是否具備所有關鍵特質的真實對話。

### 常見題型與準備方向

| 題型 | 範例與準備方向 |
| :---- | :---- |
| 申請動機 | 「為什麼選擇這個方向？」用一個真誠的故事敘述，而非戲劇性事件。 |
| 自我覺察 | 誠實陳述對社會問題的長期關注；坦承知識起點，展現開放態度。 |
| 專業知識 | 「你讀過哪些相關書籍？對哪個研究或學派印象深刻？」 |
| 分析能力 | 「你認為什麼是弱勢家庭？」——超越「經濟困難」的單一標籤，提出涵蓋情感支持、心理健康、家庭功能的多面向分析。 |
| 情境應對 | 遇到不懂的問題時，誠實回答並嘗試釐清問題，這是誠信也是學術嚴謹。 |

### 把特質融入回答

- **展現批判思考**：回答前先簡要分析問題本身——「這個問題可以從經濟、文化和政策等多個層面來分析……」
- **展現自我覺察**：多使用反映思考過程的「我」句型——「我當時的想法是……」「這個經驗讓我反思到……」
- **展現成熟穩重**：回答前稍作停頓以示尊重、避免打斷對方、保持冷靜有條理。這些溝通禮儀傳遞高度的情緒智商（EQ）。
- **展現真誠投入**：面試最後準備一至兩個有深度的問題反問教授，顯示你是渴望學術對話的未來學者。

> 誠實是一種策略：一位申請者坦承並未系統性學過心理學、知識主要來自入門書籍，這種坦誠反而被解讀為自信與安全的學術認同。面對成績不理想的提問，應主動說明原因、展現進步軌跡、提出改進計畫，把弱點轉化為「成長型心態」的正面故事。

## 四、115 學年度個人申請重要時程

| 階段 | 時間 |
| :---- | :---- |
| 第一階段（學測篩選）放榜 | 2026 年 3 月 31 日 |
| 第二階段審查資料上傳 | 起始日 2026 年 4 月 30 日；**截止日依你申請的各大學規定**（每日 9:00–21:00 開放） |
| 二階甄試與放榜 | 多集中於 5 月下旬至 6 月初 |

> 實際時程仍以甄選委員會與各校公告為準。可透過大學招生委員會聯合會的「審查資料準備指引」查詢系統，比對各校系最新指引。

## 五、最後提醒

要在社心學群的申請中脫穎而出，必須超越成績導向思維，投身一場深刻的自我探索與策略性的個人敘事建構：

- 同理心若無結構性分析的支撐，則流於淺薄。
- 科學精神若無人文關懷的溫度，則失其根本。
- 誠實與坦然面對不足，是自信與成長心態的體現。

無論書面或面試，核心都是：證明你已從「被動學習者」蛻變為「主動探究者」。
