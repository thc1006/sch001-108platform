政大社會學系的審查資料準備指引寫，備審資料的「重點是讓審查委員瞭解你的特質」。空泛的標籤（「熱心」「有同理心」）做不到這點，比較有說服力的是**用具體經歷證明、並用連貫敘事串起來的能力**。本頁帶你盤點這份「能力資產表」。

## 一、共通核心能力檢核表

無論目標是社會學、社工或心理，下表是本站整理的五項能力檢核表，每個象限都該有具體作品或經歷作為證據。

| 核心能力 | 自我檢核點 |
| :---- | :---- |
| **洞察力** | 我能否從一件生活小事（家庭互動、社團衝突、在地店家觀察），連結到更大的社會結構（世代差異、性別刻板印象）或心理學理論（認知失調、從眾效應）？ |
| **批判性思維** | 我是否曾對普遍說法或社會現象提出質疑？能否分析議題的正反兩面，並提出有根據的個人觀點？ |
| **反思與自我覺察** | 我能否清晰闡述一次失敗或挫折，並說明從中學到什麼？能否描述我的觀點如何隨時間演進？ |
| **主動探究精神** | 我是否曾因好奇心而自主規劃學習、進行研究、訪談他人，或尋找課本以外的答案？ |
| **溝通與敘事能力** | 我能否把多元經歷組織成有開頭、轉折與結尾的連貫故事，而非零散的事件列表？ |

這些特質並非單一課程能速成，而是長期養成的「思維習慣」。一份強而有力的學習歷程，價值不在某個驚天動地的單一專案，而在於它呈現出一種**連貫的模式**。這樣的歷程記錄了長期對世界保持智識與情感的互動。

## 二、學群分流能力：針對不同科系的強化重點

### 社會學系 & 社會工作學系

- **社會關懷的實踐**：不只是同情，而是透過行動（志工服務、議題倡議、校刊報導）去理解並嘗試介入社會問題。
- **結構性分析的視角**：分析問題時能超越個人歸因，看見制度、文化、歷史等結構性因素。
- **田野的耳朵與眼睛**：具備透過訪談與觀察理解他人生命經驗的初步能力。

### 心理學系

- **科學的嚴謹態度**：理解心理學是一門實證科學，對研究方法、邏輯推理與批判性思考有基本認識。
- **人文的溫暖關懷**：對人類內心世界、情緒與行為抱持深刻好奇與同理心。
- **內省的勇氣**：願意且有能力對自身的心理歷程、動機與挫折進行誠實剖析。

最高明的心理學申請者能把科學與人文結合在一起。一個理想範例：「我在陪伴自閉症孩童的志工服務中（人文關懷），對他們社交認知上的困難產生強烈好奇，這驅使我去閱讀關於鏡像神經元與心智理論的神經科學研究（科學探究）。」

## 三、社會學的想像 vs. 心理學的心態

普世基礎之上，依目標科系疊加不同的核心特質。下表是社會學與心理學在特質要求上的差異化比較。

| 核心特質 | 社會學之側重 | 心理學之側重 |
| :---- | :---- | :---- |
| 同理心 / 社會關懷 | 關注苦難的系統性成因；對集體的同理 | 關注苦難的個體經驗；對個人的同理 |
| 分析焦點 | 宏觀：社會趨勢、制度、權力、不平等 | 微觀：個體行為、心智歷程、發展與異常 |
| 溝通風格 | 對話與協商，在多元觀點中尋求共識 | 傾聽與感受，建立安全氛圍、捕捉非語言訊息 |
| 知識好奇心 | 社會理論、歷史變遷、政策分析、質性研究 | 認知神經科學、發展心理學、量化與實驗 |

**社會學的同理心要有深度**：一個僅表達「對弱勢感到同情」的申請者停留在表層；更深的申請者會進一步探究造成弱勢處境的**結構性成因**。敘述重點不應只是「我做了什麼」，而應是「我從中思考了什麼」。

**心理學要避免兩種極端**：過於「感性」（充滿未經分析的同情、缺乏科學視角），或過於「理性」（能引經據典卻冷漠、缺乏對人類處境的溫暖）。要避免成為那種「因為了解人性的一切而鄙視人性」的學者。

## 四、常見寫法對照

下面是本站整理的幾種寫法，以及它們能呈現什麼。

- **只寫「我喜歡幫助別人」** → 這類句子太常見，說明不了你的動機。換成具體、真實的經歷。
- **從校刊社經驗談到媒體再現與社會刻板印象的關係** → 這是「洞察力」：從平凡的經歷提出自己的見解。
- **承認最初的問卷設計有偏見，並說明如何修正** → 呈現你會反思、願意誠實面對失敗。
- **引用的概念用來分析現象，而不是掉書袋** → 理論是分析現實的工具，不是炫學的裝飾。
- **把自己的興趣跟該系的課程連結起來** → 看得出你研究過這個系，動機也更具體。

## 五、社會關懷與深度閱讀

在這個學群，「社會關懷」除了是情懷，也要透過研究與閱讀實踐。

- **社會學的關懷**：超越表層同情，深入社會結構分析，並轉化為改變的動力。台大社會系吳嘉苓教授的《多胞胎共和國》，關鍵評論網的書摘介紹寫她「耗時15年、橫跨3國、進行上百場深度訪談」，探討台灣人工生殖技術與政策如何跟「社會期待、國家榮譽、特殊的醫療市場」交織。學者 Michael Burawoy 更倡議「公共社會學」，主張學者應懷抱介入社會的熱情。
- **心理學的關懷**：更強調內在動機的真誠與持久。台大心理系黃榮村教授在系刊專訪中說，他與年輕人聊天或演講時，「總要提醒他／她們莫忘初衷，不要忘了當初為什麼來念這一行的心意」。
- **深度閱讀**：比起「讀了多少」，更值得準備的是「如何去讀」。社會學的閱讀要培養分析與質疑的能力，可以試著把自己當成作者的「論敵」，在對話中找到新方向；心理學的閱讀則要批判性地吸收，並思考「科學」本身是什麼。
