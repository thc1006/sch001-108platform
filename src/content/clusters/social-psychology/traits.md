# 社會與心理學群：教授看重的特質與能力

在這個學群，最能打動教授的並非空泛的標籤（「熱心」「有同理心」），而是一種 **被證實的能力**（demonstrated capacity）——透過具體經歷證明、並用連貫敘事串起來的能力。本頁帶你盤點這份「能力資產表」。

## 一、共通核心能力：所有社心科系的基石

無論目標是社會學、社工或心理，以下五項能力是頂尖大學社會科學領域普遍重視的基石。請把它當作檢核表，每個象限都該有具體作品或經歷作為證據。

| 核心能力 | 自我檢核點 |
| :---- | :---- |
| **洞察力** | 我能否從一件生活小事（家庭互動、社團衝突、在地店家觀察），連結到更大的社會結構（世代差異、性別刻板印象）或心理學理論（認知失調、從眾效應）？ |
| **批判性思維** | 我是否曾對普遍說法或社會現象提出質疑？能否分析議題的正反兩面，並提出有根據的個人觀點？ |
| **反思與自我覺察** | 我能否清晰闡述一次失敗或挫折，並說明從中學到什麼？能否描述我的觀點如何隨時間演進？ |
| **主動探究精神** | 我是否曾因好奇心而自主規劃學習、進行研究、訪談他人，或尋找課本以外的答案？ |
| **溝通與敘事能力** | 我能否把多元經歷組織成有開頭、轉折與結尾的連貫故事，而非零散的事件列表？ |

這些特質並非單一課程能速成，而是長期養成的「思維習慣」。一份強而有力的學習歷程，價值不在某個驚天動地的單一專案，而在於它呈現出一種**連貫的模式**——長期對世界保持智識與情感互動的紀錄。

## 二、學群分流能力：針對不同科系的強化重點

### 社會學系 & 社會工作學系

- **社會關懷的實踐**：不只是同情，而是透過行動（志工服務、議題倡議、校刊報導）去理解並嘗試介入社會問題。
- **結構性分析的視角**：分析問題時能超越個人歸因，看見制度、文化、歷史等結構性因素。
- **田野的耳朵與眼睛**：具備透過訪談與觀察理解他人生命經驗的初步能力。

### 心理學系

- **科學的嚴謹態度**：理解心理學是一門實證科學，對研究方法、邏輯推理與批判性思考有基本認識。
- **人文的溫暖關懷**：對人類內心世界、情緒與行為抱持深刻好奇與同理心。
- **內省的勇氣**：願意且有能力對自身的心理歷程、動機與挫折進行誠實剖析。

最高明的心理學申請者能展現「科學—人文」的綜合體。一個理想範例：「我在陪伴自閉症孩童的志工服務中（人文關懷），對他們社交認知上的困難產生強烈好奇，這驅使我去閱讀關於鏡像神經元與心智理論的神經科學研究（科學探究）。」

## 三、社會學的想像 vs. 心理學的心態

普世基礎之上，依目標科系疊加不同的核心特質。下表是社會學與心理學在特質要求上的差異化比較。

| 核心特質 | 社會學之側重 | 心理學之側重 |
| :---- | :---- | :---- |
| 同理心 / 社會關懷 | 關注苦難的系統性成因；對集體的同理 | 關注苦難的個體經驗；對個人的同理 |
| 分析焦點 | 宏觀：社會趨勢、制度、權力、不平等 | 微觀：個體行為、心智歷程、發展與異常 |
| 溝通風格 | 對話與協商，在多元觀點中尋求共識 | 傾聽與感受，建立安全氛圍、捕捉非語言訊息 |
| 知識好奇心 | 社會理論、歷史變遷、政策分析、質性研究 | 認知神經科學、發展心理學、量化與實驗 |

**社會學的同理心要有深度**：一個僅表達「對弱勢感到同情」的申請者停留在表層；更深的申請者會進一步探究造成弱勢處境的**結構性成因**。敘述重點不應只是「我做了什麼」，而應是「我從中思考了什麼」。

**心理學要避免兩種極端**：過於「感性」（充滿未經分析的同情、缺乏科學視角），或過於「理性」（能引經據典卻冷漠、缺乏對人類處境的溫暖）。要避免成為那種「因為了解人性的一切而鄙視人性」的學者。

## 四、教授的內心 OS

理解審查教授深夜閱卷時的內心劇場，你就能更精準地準備。

- **「又來了，『我喜歡幫助別人』……」** → 教授對陳腔濫調極度疲乏。他們要的是具體、真實、獨一無二的動機故事。
- **「喔？他從校刊社經驗談到了媒體再現與社會刻板印象的關係。」** → 這就是「洞察力」。教授尋找能把平凡經歷提煉出不凡見解的潛在學者。
- **「他承認最初的問卷設計有偏見，而且說明了如何修正。這孩子懂得反思。」** → 誠實面對失敗，是自信與成長心態的體現。
- **「嗯，他引用的概念用對地方了，是用來分析，而不是掉書袋。」** → 理論是分析現實的工具，不是炫學的裝飾。
- **「看得出來他真的研究過我們系，還把興趣跟我們系的課程連結起來。」** → 這展現「強烈動機」與「申請誠意」，是錄取的臨門一腳。

## 五、教授觀點：社會關懷與深度閱讀

教授不只把「社會關懷」視為情懷，更視為需透過嚴謹學術實踐體現的核心能力。

- **社會學的關懷**：超越表層同情，深入社會結構分析，並轉化為改變的動力。台大社會系吳嘉苓教授耗時十五年訪談上百位女性，探討人工生殖技術如何與國家榮譽、醫療市場交織——研究本身就是一種深刻的社會關懷。學者 Michael Burawoy 更倡議「公共社會學」，主張學者應懷抱介入社會的熱情。
- **心理學的關懷**：更強調內在動機的真誠與持久。台大心理系黃榮村教授反覆提醒學子「莫忘初衷」、「以蒼生為念」——這份初衷是支撐學者走過漫長生涯的根本動力。
- **深度閱讀**：教授強調的不是「讀了多少」，而是「如何去讀」。社會學的閱讀要培養分析與質疑的能力，最高層次是把自己當成作者的「論敵」，在對話中找到新方向；心理學的閱讀則需批判性吸收（黃光國教授指出，若只直接移植西方理論，常難以解釋台灣社會），並對「科學」本身有更深的哲學思辨。
