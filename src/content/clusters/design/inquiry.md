「高中自主學習計畫與成果」是申請入學審查資料裡多元表現的一項。各系採計哪幾項，以當年度的校系分則為準。

親子天下的整理寫，自主學習計畫沒有規定格式，架構寫清楚學習主題、目標、內容、時數和方法就可以。文中引述國立大學教師，大學端並不期待高中生交出多艱深、多學術性的報告，只要能呈現對問題的敏感度、洞察力和解決問題的能力。計畫失敗也可以寫，清楚說明看出哪些問題、怎麼改進，就是完整的自主學習歷程。計畫範例可以看教育部 108 課綱資訊網的自主學習專區。

成果報告可以照這五段寫：動機、過程、遇到的問題和解法、成果、反思。

## 設計思考五步驟

設計思考是以使用者為中心的方法，創始者是美國設計公司 IDEO 的創辦人 David Kelley。這五步可以直接當自主學習計畫的進度，看的人也一眼看得出你懂設計怎麼做。

| 步驟 | 做什麼 |
|---|---|
| 同理（Empathize） | 觀察、接觸、聆聽使用者，記錄他們的行為與情緒，多問為什麼 |
| 定義（Define） | 把蒐集到的資料分類收斂，找出使用者的痛點，用一句話寫下需求 |
| 發想（Ideate） | 暫時不管可行性，和團隊一起腦力激盪 |
| 原型（Prototype） | 用快速、便宜的方式把想法做出來，例如用紙板模擬背包的造型 |
| 測試（Test） | 拿原型反覆檢驗是否解決了問題，蒐集回饋後回到定義再修改 |

## 各方向的題目

下面每個題目都附一個探究問題和可以交出的成果，可以直接用，也可以換成你身邊的對象。

| 方向 | 題目 | 探究問題 | 可以交出的成果 |
|---|---|---|---|
| 視覺傳達、商業設計 | 替家鄉一間沒有識別系統的老店，重新設計標誌、招牌和包裝 | 好的品牌識別怎麼影響客人的感受？ | 品牌識別提案、設計過程紀錄 |
| 視覺傳達、商業設計 | 把你關心的數據做成資訊圖表，例如校園垃圾量、社區人口 | 同一組數字，怎麼畫最容易看懂？ | 資訊圖表、前後版本對照和讀者回饋 |
| 視覺傳達、商業設計 | 記錄生活圈裡的招牌字體 | 這些招牌用了哪些字體，為什麼？ | 街道字體觀察報告 |
| 工業、產品設計 | 選一個你或家人每天用得不順手的東西，走完設計思考五步驟 | 這個東西忽略了哪一群使用者？ | 改良原型（紙、黏土、3D 列印都可以）、使用者測試紀錄 |
| 工業、產品設計 | 研究通用設計的原則，替長輩或身障者改良一件物品 | 他們用這個東西時卡在哪裡？ | 原則整理、改良提案 |
| 互動設計、UI/UX | 選一個難用的 App 或售票機，觀察別人怎麼用 | 使用者在這個介面上卡在哪裡？ | 使用者旅程地圖、改良後的介面草案，免費的原型工具就夠用 |
| 互動設計、UI/UX | 用手機的螢幕報讀功能試用一個網站，或請長輩試用 | 這個網站對他們哪裡不友善？ | 試用紀錄、改善清單 |
| 建築、空間、室內設計 | 找校園裡一個沒人想待的角落 | 什麼讓一個空間讓人想停留，或想離開？ | 空間分析、草模、改造提案圖 |
| 建築、空間、室內設計 | 踏查家鄉的老建築或街屋 | 這棟建築可以怎麼保存、再利用？ | 踏查紀錄、實測草圖、再利用構想 |
| 數位多媒體、動畫 | 選一個你想說的故事，畫分鏡、做一段短動畫 | 怎麼用分鏡把故事講清楚？ | 分鏡腳本、短動畫 |
| 數位多媒體、動畫 | 分析一款你喜歡的遊戲的關卡 | 這些關卡怎麼引導玩家？ | 關卡分析、自己設計的一個關卡 |
| 服裝設計 | 用回收物或自然材質做服飾配件 | 這些材料能不能做成可以穿戴的東西？ | 材質實驗紀錄、配件成品 |
| 服裝設計 | 研究某個年代或文化的服裝 | 這種服裝的特色從哪裡來？ | 研究筆記、轉化成自己的設計提案 |

也可以把設計和其他議題連起來，例如：

- 生成式 AI：實際用幾種工具，整理 AI 能幫設計做什麼、做不到什麼，寫下你自己的看法。
- 永續設計：材料、包裝、產品怎麼減少浪費。
- 地方創生：用設計幫在地的店家、產業或文化。
- 社會設計：替弱勢族群或公共議題提出設計方案。
- 設計和心理：例如色彩和情緒、介面和使用行為。

## ColleGo! 各學類建議的體驗

ColleGo! 每個學類頁都有「學類體驗」，列出高中可以先做的事。六個學類的摘要：

| 學類 | ColleGo! 的建議 |
|---|---|
| 商業設計 | 把生活觀察做成素描、插畫、攝影、影片或海報，拿去和人溝通、看回饋；看到好或不好的設計，想想「如果是我會怎麼做？」 |
| 工業設計 | 觀察並記錄家具、交通工具、3C 產品的造型和結構；找生活中可以有更好使用經驗的事，想想怎麼改變物品的使用行為，記下觀察和思考；追蹤米蘭家具展、荷蘭設計週這類國際展的報導 |
| 媒體設計 | 比較電玩和動畫的畫面設計，記下分析；把生活觀察剪成短影音發布，看傳播後的回饋 |
| 建築 | 以特定作品為題，分析吸引你的地方；讀建築書籍雜誌；練習繪製建築圖面；看各行業的人怎麼口述想法，練習講故事 |
| 空間設計 | 找建築、景觀、室內設計的名人案例，分析背後的設計原理；觀察陽光、天氣、地勢、歷史對空間規劃的影響 |
| 服裝設計 | 研究布料的材質，畫一套服裝並標示使用場合和布料；看展覽、時裝秀，把有感的元素記錄下來 |

## 做得好的方法

- 問題從自己的生活裡找。家裡、通勤路上、校園裡發現的問題，最有說服力。
- 留下過程：草圖、被推翻的版本、做壞的原型照片、訪談筆記，都證明是你自己做的。
- 誠實寫哪裡沒做好、為什麼。
- 反思時連到想念的系，例如這個專題讓你更想學什麼。

## 常見的地雷

- 題目太大。「研究台灣設計產業」這種題目高中生做不完也做不深，小題目做深比較好。
- 只有結論，沒有過程。
- 把網路文章剪貼成報告，沒有自己的觀察、訪談或實作。
- 主題和想念的系沒有關係。
- 抄別人的計畫或作品。參考了誰，要寫出來源。

## 可以用的資源

- ColleGo! 各學類頁：看這個學類學什麼、建議高中先做什麼。
