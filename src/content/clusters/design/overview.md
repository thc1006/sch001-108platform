ColleGo! 把設計相關科系歸在建築設計學群，簡介寫這個學群探究自然社會環境、都市建築規畫、室內設計、商業設計等「結合人文藝術與工程技術領域，對物體、空間或環境同時能賦予實用與美學之特性」。學群下有九個學類：媒體設計、建築、都市計畫、空間設計、工業設計、工藝、商業設計、服裝設計、藝術設計。工業設計、工藝、商業設計、服裝設計、藝術設計同時列在藝術學群；媒體設計、建築兩個學類則分別列在資訊、工程學群。

## 其中六個學類學什麼

| 學類 | ColleGo! 寫的學習內容 |
|---|---|
| 商業設計 | 整合視覺傳達、商業行銷、藝術人文、數位科技，著重美感訊息與產品的有效溝通，應用在平面設計、品牌形象、廣告、包裝、插畫等 |
| 工業設計 | 使用者導向的工業產品設計，學產品創意發想、2D 電腦繪圖與 3D 建模、材料與製造程序、機構與人因工程、品牌與行銷 |
| 媒體設計 | 數位動畫與互動媒體，學色彩學、素描、電腦繪圖、3D 動畫、遊戲設計 |
| 建築 | 結合人文藝術與工程技術，學建築設計、建築史、都市規劃，也學工程力學、建築結構系統、施工估價 |
| 空間設計 | 景觀學系做都市開放空間與地景營造；室內設計學系掌握人體尺度、傢飾材料及微物理環境調節 |
| 服裝設計 | 設計與製作服裝，學服裝畫、打版、立體裁剪、織品材料、服裝史與服飾行銷 |

## 各系學什麼

雲科大、臺科大、北科大是科技大學，普通科和高職生的入學管道見〈申請備審與面試要點〉的「科技大學與統測」一節。

| 校系 | 官網或 ColleGo! 寫的 |
|---|---|
| 臺藝大視覺傳達設計學系 | 以整合視覺、設計與科技為核心，著重數位化、互動性應用及 UI/UX 體驗整合 |
| 雲科大視覺傳達設計系 | 發展品牌形象規劃、五感體驗融合、文化創意加值、數位媒體運用 |
| 臺科大設計系 | 重點領域是產品設計、視覺行銷設計、數媒互動設計、設計管理 |
| 臺師大設計學系 | 分視覺設計、產品設計兩項專業，另有室內設計學分學程 |
| 實踐大學工業產品設計學系（臺北） | 學習內容架構在使用者關懷、產業實踐及社會創新之間，提供國內外實習和國際交換學生的機會 |
| 北科大工業設計系 | 學士班分產品設計、家具與室內設計兩組 |
| 成大工業設計學系 | 綜合美學、工學及商學；必修有微積分、普通物理學、設計方法、人類因素學、機構學 |
| 北科大互動設計系 | 培育兼具設計與程式專業的人才；系網寫，業界對使用者介面（UI）與使用者經驗（UX）設計等人才的需求，是系名與發展主軸的由來 |
| 世新大學數位多媒體設計學系 | 以電腦為主要工具，做 2D 及 3D 動畫創作、遊戲製作、虛實互動設計與應用 |
| 實踐大學服裝設計學系（臺北） | 長期與國際院校合作舉辦學術交流與設計工作坊，合作院校包括英國中央聖馬丁藝術與設計學院、義大利 Istituto Marangoni、美國紐約流行時尚設計學院、日本文化服裝學院等 |

ColleGo! 空間設計學類的對應校系裡，室內設計有中原、亞洲大學的室內設計學系，逢甲的室內設計學士學位學程，大葉空間設計學系的室內設計組；媒體設計學類裡，系名有動畫或遊戲的是北藝大動畫學系，實踐大學高雄校區的數位多媒體遊戲設計學系和電腦動畫學士學位學程。

北科大設計學院另有建築系，以及大一不分系、大二選主修的創意設計學士班。實踐大學高雄校區另有時尚設計學系。

## 建築系念幾年

ColleGo! 建築學類列的建築學系與學院學士班，12 所大學裡有 8 所念五年：東海、淡江、中原、銘傳、實踐、高雄大學、聯合、金門大學。成大分四年制與五年制兩組，大二下學期選；逢甲建築專業學院的建築設計學程五年、室內設計學程四年；文化大學建築及都市設計學系、南華大學建築學系是四年。

## 生成式 AI

台灣設計研究院 2025 年的文章〈【設計力研究系列2】AI世代的設計突圍—重新思考產業與人才的未來〉整理《2024年台灣設計力報告》，寫台灣設計師已普遍把生成式 AI 用在日常工作。文章說 AI 無法自行辨識「什麼是值得被解決的問題」；在 AI 協作之下，設計師的角色「不只是創作者，更是指揮者」，要引導 AI 產出內容，並「以專業眼光調校細節、定錨策略」。報告也指出，學校教育未能即時銜接 AI 應用下的實務需求，學用落差日益明顯。
