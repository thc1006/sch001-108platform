# 設計學群申請備審與面試要點

> 對應 2026 年 / 115 學年度大學申請入學｜給高中生與家長的升學指南

設計學群的升學，是 18 學群中「管道最分歧、規定最因校而異」的一群。同樣叫「設計系」，有的考術科、有的不考；有的要實體作品集、有的只收 PDF；有的偏學術、有的偏實務。

> **唯一的鐵則**：逐一查閱目標校系官網的「審查資料準備指引」與當年度招生簡章。

## 一、升學管道與採計（115 學年度概況）

設計學群主要有兩大升學體系。

### 1. 普通大學：大學個人申請 / 繁星 / 分發

- **學測採計**：多採計國文、英文，部分校系加採數 A/數 B 或社會，**最多採計四科**。
- **術科測驗**：部分設計校系於第一階段加採「大學術科考試」成績（美術組考素描、彩繪技法、創意表現、水墨、美術鑑賞等，依校系指定）。**並非所有設計系都要術科**——是否採計、採計哪幾項，因校系而異。
- **第二階段**：由各校系自辦，常見項目為審查資料（含作品集）、面試、實作測驗、第二階段術科（設計素描、創意表現、實作等）。第二階段中「學測成績占比多在 50% 以下」，**作品集、面試、術科是真正的決勝場**。

### 2. 技職體系：四技二專統一入學測驗（統測）— 設計群

- 報考設計群者，考科為國文、英文、數學、專業科目一、專業科目二。
- **專業一（學科）**：色彩原理、設計概論、造形原理。
- **專業二（術科）**：繪畫基礎、設計基礎、設計圖法。
- 之後可循「甄選入學」（採計統測 + 備審 + 面試/實作）或「登記分發」升學。

> **行動提醒**：高一、高二就要確認自己走「學測」還是「統測」體系，兩者準備方向差異極大。普通高中生通常走學測管道；高職設計群學生走統測管道。

## 二、備審資料（學習歷程檔案）準備要點

115 學年度個人申請第二階段，審查資料以「學習歷程檔案」為主，參採同學須上傳已建置的學習歷程檔案，亦可採「自製 PDF」上傳。

### 上傳規格（以 115 學年度為準，實際以簡章為準）

- 第二階段審查資料上傳期程約落在 4 月底至 5 月初（115 學年度約為 4/30–5/5，每日 9:00–21:00）。
- **每一審查項目單一 PDF 檔案大小多以 5MB 為限。**
- 建議提早上傳，避免最後一天網路壅塞。

### 設計學群備審的特殊項目：作品集

- 部分設計校系會將「作品集」列為**指定項目**（而非標準項目），須依該校系審查指引格式繳交。
- 作品集策略請參閱本系列〈多元表現亮點策略〉的作品集 Portfolio 全攻略，核心原則：**重質不重量、過程重於成果、真實重於完美、切忌套版與罐頭文字**。

### 備審撰寫：招聯會「三重二不」原則

招聯會明訂審查原則：**重視學習過程、重視能力養成、重視學習成果展現的素養；不是以量取勝、不是學系所列項目越多越好。** 設計教授閱歷無數，對「充場面」的資料一眼識破——誠實、有歷程、有反思的資料才是王道。

備審各項目（自述、課程學習成果、多元表現）撰寫，建議套用 **STAR / OPQ 等結構**，並落實「動機 → 過程 → 問題解決 → 成果 → 反思」的敘事公式。

## 三、面試要點

設計學群第二階段普遍含面試。面試的本質，是教授「驗證你備審與作品集真實性、並感受你這個人」的場合。

### 必考題與準備方向

1. **「請自我介紹」（約 1–2 分鐘）**
   - 不是瞎聊。要在開場「設下伏筆」，點出你的興趣與特色，引導教授「主動想問下去」。
   - 結構建議：姓名 → 你對設計的興趣從何而來 → 你最想談的一兩個亮點（作品、經歷）。

2. **「你為什麼想讀設計 / 為什麼想讀『這個』設計系？」**
   - 系友直言：「這題答不出來基本上就完蛋了。」
   - 必須能清楚說明：**為什麼是設計**（而非美術）、**為什麼是這個分流**（例如為什麼是工業設計而非平面設計）、**為什麼是這間學校的這個系**（而非隔壁競爭校系）。
   - 答案來源：你對目標校系課程地圖、師資專長、定位特色的研究。

3. **作品集介紹**
   - 面試「通常都會被問到作品集」。事先選定 1–2 件你最喜歡、最能展現特色、且與該系最相關的作品，練熟「如何向教授介紹」。
   - 介紹時聚焦：設計動機、過程中的思考與卡關、學到什麼——而非炫耀技法。

4. **設計觀 / 時事題**
   - 可能被問對某個設計現象、某個社會議題、或 AI 對設計影響的看法。平日累積「評論設計好壞」的能力與觀點即派上用場。

### 面試展現的特質

教授在面試中尋找：**與人合作的能力、解決問題的能力、領導力、企圖心、對設計的熱情、同理心。** 回答時用「具體事例」佐證這些特質，勝過空講形容詞。

### 面試地雷

- 講話沒有主軸、東拉西扯——「敢講當然好，但不能講得沒重點」。
- 對目標校系一無所知，答不出「為什麼選這裡」。
- 作品集講不清楚自己的設計歷程（代表作品可能不是自己主導）。
- 缺乏自信、或態度過度浮誇。

## 四、術科要點（適用需考術科的校系）

並非所有設計校系都考術科，但若你的目標校系採計，以下要點來自 IOH 系友與設計教學現場經驗。

### 心態：技法是其次，原創性與想法才是核心

- 系友與教授一致強調：「不用過於擔心美術基礎，因為老師想看到的是原創性。」班上甚至有人用彩色筆考術科照樣正取。
- 會不會畫圖，差別只在於「你擁有多少呈現想法的技巧」，而不是錄取與否的關鍵。

### 平日積累比考前惡補有效

- 設計術科（尤其工業設計、創意表現類）常與「社會議題、時事」相關。平日多留心時事、閱讀設計書籍、培養「評論設計好壞」的眼光，考場才激盪得出原創設計。
- 美感來自長期生活與環境累積，無法短期速成——越早開始「養眼睛」越好。

### 表現方式可多元

- 除了畫，可善用「文字圖說」解釋創作概念，幫助評審理解你的設計邏輯。
- 重點永遠是「想法的完整傳達」，而非單純的繪畫技巧炫技。

### 第一階段術科 vs 第二階段術科

| 階段 | 內容 |
|---|---|
| 第一階段 | 多為大學術科考試的指定科目（素描、彩繪、創意表現等），作為篩選門檻 |
| 第二階段 | 各校系自辦，常見設計素描、創意表現、實作測驗，更貼近該系的專業取向 |

## 五、申請時程與行動清單（以 115 學年度節奏為參考）

| 時間點 | 任務 |
|---|---|
| 高一～高二 | 確認走學測或統測體系；開始累積作品與觀察筆記；考慮是否需準備術科 |
| 高三上 | 完成學測 / 統測準備；補齊作品集代表作；研究目標校系審查指引與簡章 |
| 學測 / 統測後 | 對照成績與校系篩選標準，選定申請校系；若需術科，完成大學術科考試 |
| 一階放榜後 | 依各通過校系的審查指引，客製化作品集與備審 PDF |
| 二階審查資料上傳期（約 4 月底–5 月初） | 提早上傳，注意 5MB/項目限制 |
| 第二階段甄試 | 面試、術科、實作——練熟「說作品」、研究透校系特色 |

> **務必每年確認**：大學申請入學的確切時程、各校系採計項目與比例、作品集規格，皆以**該年度招生簡章與各校系審查資料準備指引**為準。本頁數據對應 115 學年度公開資訊。

## 六、常見問題快問快答

- **Q：我不會畫畫，可以申請設計系嗎？**
  A：可以。許多設計組別不考術科；考術科的校系也明言「想看原創性而非畫技」。但你需要其他能呈現想法的方式（數位、模型、文字圖說）。

- **Q：作品集一定要做得很精美嗎？**
  A：不。重點是「重質不重量、展現完整設計歷程」。過度修圖的「樣品屋」反而扣分。

- **Q：沒得過設計大獎，面試會很吃虧嗎？**
  A：不會。教授清楚高中生程度，在意的是過程與反思，不是名次。

- **Q：AI 工具可以用在備審 / 作品集嗎？**
  A：AI 可作為輔助發想工具，但作品集與自述的「核心想法、設計決策、文字」必須是你自己的。罐頭式 AI 文字「文字個性不一致」會被識破；直接拿 AI 生成圖當作品更是真實性與誠信的大問題。
