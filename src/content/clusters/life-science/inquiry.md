台大生命科學系的準備指引寫，自主學習計畫與成果要呈現「在高中期間的自主學習計畫、執行內容、成果與反思」。親子天下整理，自主學習計畫沒有規定格式，架構寫清楚學習主題、目標、內容、時數和方法就可以；計畫失敗，只要清楚說明看出哪些問題、怎麼改進，也是完整的自主學習歷程。

## ColleGo! 各學類的體驗建議

ColleGo! 每個學類頁都有「學類體驗」，建議高中生可以做的事。以下摘出和探究、自主學習有關的部分：

| 學類 | ColleGo! 的建議（摘要） |
|---|---|
| 生命科學 | 觀察一種生命現象，找理論理解它；投入一個生物實驗；讀科學期刊或雜誌裡的實驗，試著還原實驗設計；把觀察或實驗連結到理論，寫成小論文 |
| 生物科技 | 做實驗或參加科學專題，找出實驗遇到問題的原因並解決，記錄實驗程序與條件 |
| 生化 | 找一個生活中的生化機轉，例如糖分的分解與轉換，觀察並記錄；練習用 Excel 記錄數據；讀統計書，了解重複性、準確度與精密度 |
| 生物資訊 | 學程式設計，試著用程式整合分析資料；熟悉微積分 |
| 生醫工程 | 從生活中找問題，例如老人居家照護、醫院裡的不便，再想怎麼解決 |
| 植物保護 | 飼養小昆蟲或植物，天天觀察記錄，一段時間後統計分析，找出影響生長的條件 |
| 生態 | 加入環境、生物相關社團；以台灣或特定區域的生態條件思考環境議題；學 Excel、統計軟體 R |
| 食品生技 | 關注食安議題，比較不同來源怎麼處理同一件事；在烹飪或烘焙時記錄不同操作程序帶來的變化 |

## 題目例子

下表是本站寫的例子，不是哪個系的要求。表中除了植物相調查、序列比對與族群成長模擬，都是可以設對照組、重複測量、用數字記錄結果的實驗題目。

| 方向 | 題目例子 |
|---|---|
| 植物生理 | 紅光、藍光、白光對某種植物發芽率或株高的影響；不同濃度的咖啡因、鹽或糖對種子萌發的影響 |
| 微生物 | 綠茶、薑、蒜、蜂蜜萃取物的抑菌效果（抑菌圈法）；溫度或 pH 對酵母菌發酵速率的影響，以產生的 CO₂ 體積量化 |
| 動物行為與生態 | 校園螞蟻對不同食物的偏好；光照、溫度對麵包蟲或果蠅活動力的影響；校園植物相調查 |
| 食品 | 貯存溫度、包裝對某種食品褐變或腐敗速度的影響；不同處理方式對食物維生素 C 含量的影響（碘滴定法） |
| 生物資訊與數理 | 用 NCBI 資料庫比對某個基因或蛋白質序列；用邏輯斯型成長模型模擬族群成長 |
