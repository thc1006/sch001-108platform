台大生命科學系 115 學年度的準備指引寫，自主學習計畫與成果要呈現「在高中期間的自主學習計畫、執行內容、成果與反思」。生科是實驗科學，一個自己動手做完的小探究，能直接說明你會做科學。題目大不大、器材好不好都沒關係，要緊的是觀察、提問、查資料、設假說、設計實驗、分析、反思這一整套流程，你是不是自己走過一遍。

## 好題目的四個條件

1. 做得到：用學校實驗室或家裡拿得到的器材和材料就能做。
2. 能控制變因：說得出自變項、應變項、控制變項，也能設對照組。
3. 能量化：結果用數字記錄，例如株高、菌落數、發芽率、反應時間，不只靠感覺。
4. 夠小：一學期或一學年內能重複測量幾次。「我想研究癌症」太大；「某濃度的咖啡因會不會影響綠豆發芽率」就做得到。

常見的錯誤是題目訂得太大、太前沿，例如基因編輯、幹細胞、癌症標靶，最後只能整理文獻，沒辦法動手。一個自己做完的綠豆實驗，比只會背名詞的癌症研究有說服力。

## 計畫怎麼寫

自主學習計畫沒有規定格式，可以照這六項寫：

1. 學習動機：什麼經驗或觀察讓你想探究這個主題，寫你自己的事。
2. 學習目標：想回答什麼問題、學會什麼能力，寫得具體到之後能檢查。
3. 方法與進度：分週或分月排。讀哪些書和文章、做哪些實驗或觀察、要訪談誰。
4. 預期成果：研究報告、實驗數據、觀察日誌、心得文章。
5. 執行紀錄：過程中實際發生的事，包括卡關、調整和失敗。
6. 成果與反思：得到什麼結論、學到什麼、重來一次會怎麼改，和你想念的科系有什麼關係。

計畫失敗也沒關係，說清楚你看出哪些問題、怎麼改進，就是完整的自主學習歷程。

## ColleGo! 各學類的體驗建議

ColleGo! 每個學類頁都有「學類體驗」，建議高中生可以做的事。以下摘出和探究、自主學習有關的部分：

| 學類 | ColleGo! 的建議（摘要） |
|---|---|
| 生命科學 | 觀察一種生命現象，找理論理解它；投入一個生物實驗；讀科學期刊或雜誌裡的實驗，試著還原實驗設計；把觀察或實驗連結到理論，寫成小論文 |
| 生物科技 | 做實驗或參加科學專題，找出實驗遇到問題的原因並解決，記錄實驗程序與條件 |
| 生化 | 找一個生活中的生化機轉，例如糖分的分解與轉換，觀察並記錄；練習用 Excel 記錄數據；讀統計書，了解重複性、準確度與精密度 |
| 生物資訊 | 學程式設計，試著用程式整合分析資料；熟悉微積分 |
| 生醫工程 | 從生活中找問題，例如老人居家照護、醫院裡的不便，再想怎麼解決 |
| 植物保護 | 飼養小昆蟲或植物，天天觀察記錄，一段時間後統計分析，找出影響生長的條件 |
| 生態 | 加入環境、生物相關社團；以台灣或特定區域的生態條件思考環境議題；學 Excel、統計軟體 R |
| 食品生技 | 關注食安議題，比較不同來源怎麼處理同一件事；在烹飪或烘焙時記錄不同操作程序帶來的變化 |

## 題目例子

下面是一些題目例子，可以照自己的興趣和手邊的器材改成自己的題目。

| 方向 | 題目例子 |
|---|---|
| 植物生理 | 紅光、藍光、白光對某種植物發芽率或株高的影響；不同濃度的咖啡因、鹽或糖對種子萌發的影響 |
| 微生物 | 綠茶、薑、蒜、蜂蜜萃取物的抑菌效果（抑菌圈法）；溫度或 pH 對酵母菌發酵速率的影響，以產生的 CO₂ 體積量化 |
| 動物行為與生態 | 校園螞蟻對不同食物的偏好；光照、溫度對麵包蟲或果蠅活動力的影響；校園植物相調查 |
| 食品 | 貯存溫度、包裝對某種食品褐變或腐敗速度的影響；不同處理方式對食物維生素 C 含量的影響（碘滴定法） |
| 生物資訊與數理 | 用 NCBI 資料庫比對某個基因或蛋白質序列；用邏輯斯型成長模型模擬族群成長 |

## 做實驗的五個細節

1. 設對照組：沒有對照組，就看不出結果是不是你改的那個條件造成的。
2. 重複測量：每組至少做 3 次，寫出平均和變異，例如標準差或誤差線。只做一次的結果不夠。
3. 用數字記錄：用表格和圖表呈現，不要只寫「長得比較好」。
4. 誠實寫限制：樣本太少、變因沒控制好、器材精度不夠，都寫出來。
5. 讀一點英文資料：查資料時找一兩篇英文科普文章或研究摘要，在報告裡說你怎麼理解它。

## 和想念的學類連起來

已經有想念的學類，讓自主學習的主題和它呼應：

- 生命科學、生物科技：分子、遺傳、微生物相關的探究。
- 食品科學：食品微生物、加工、保存、品管。
- 生物資訊：用程式分析生物資料。
- 植物保護、生態：野外觀察、生物多樣性、植物病蟲害的長期紀錄。

在反思裡寫出這次探究讓你確認或修正了對哪個領域的興趣，備審的各項資料就串得起來。
