# 生命科學學群自主學習與探究專題方向指南

> 本頁聚焦「自主學習計畫」與「探究專題」的發想、設計與執行,提供可行的主題方向與範例。資料更新至 2026 年 5 月(115 學年度適用),所有實質觀點均經至少 5 份權威來源交叉查證。

## 一、為什麼自主學習與探究專題對生科申請特別關鍵

108 課綱下,「高中自主學習計畫與成果」是生科系明文參採的審查項目;「自然科學領域探究與實作成果」更被台大單獨列出並「著重」。對生科這個本質是實驗科學的學群來說,這兩項是你證明「會做科學」最直接的舞台。

生科自主學習與探究專題的精神,可以濃縮成一句話:

> **把一個你真正好奇的生命現象,變成一個「可以動手檢驗」的小問題,然後誠實地走完一遍科學流程。**

題目大不大、器材好不好,都不是重點。重點是這一遍流程——觀察、提問、查文獻、設假說、設計、操作、分析、反思——你是不是真的走過。

## 二、好題目的四個條件

一個適合高中生的生科探究 / 自主學習題目,應同時滿足:

1. **可操作**:用高中實驗室、學校或家裡能取得的器材與材料就能進行。
2. **可控制變因**:你能明確指出自變項、應變項、控制變項,並能設對照組。
3. **可量化**:結果能用數字記錄(株高、菌落數、發芽率、反應時間、吸光值等),而非只憑感覺。
4. **夠小**:能在一學期或一個學年內完成數次重複測量。「我想研究癌症」不行;「我想知道某濃度的咖啡因是否影響綠豆發芽率」可以。

> **一個常見錯誤**:把題目訂得太大、太前沿(基因編輯、幹細胞、癌症標靶),結果只能空談文獻、無法實作。教授寧可看到一個你親手做完的綠豆實驗,也不要一個你只會背名詞的「癌症研究」。

## 三、可行的探究專題方向(依學類分類)

以下方向符合「可操作、可控制、可量化、夠小」原則。**請當成發想起點,再依你的興趣與在地條件改造成屬於你自己的題目。**

### A. 植物 / 生理方向(器材門檻最低,最適合入門)

- 不同光照波長(紅光 / 藍光 / 白光,可用色光膜)對某植物發芽率或株高的影響。
- 不同濃度的某天然物(咖啡因、鹽、糖、廚餘堆肥液)對種子萌發或根長的影響。
- 不同土壤排水條件 / 含水量對某盆栽生長的影響。
- 植物向光性、向地性的量化觀察與計時。

### B. 微生物方向(需基本無菌操作,學校實驗室可行)

- 不同天然萃取物(綠茶、薑、蒜、蜂蜜)對細菌生長的抑制效果(抑菌圈法)。
- 環境表面(門把、手機、鍵盤)的微生物採樣與菌落數比較。
- 不同溫度 / pH 對酵母菌發酵速率的影響(以產生 CO₂ 體積量化)。
- 自製優格時不同發酵時間對酸度的影響。

### C. 動物行為 / 生態方向(多在田野,需耐心與長期記錄)

- 校園或社區某類昆蟲(如螞蟻)對不同食物的偏好行為實驗。
- 潮間帶、校園、公園的物種觀察與生物多樣性記錄(可長期)。
- 光照、溫度對某類無脊椎動物(如麵包蟲、果蠅)活動力的影響——成大生科面試考古題正出現過「麵包蟲在高壓環境下活動力」的科展案例。
- 賞鳥日誌、校園植物相調查的系統化、量化整理。

### D. 食品科學方向(適合對食品生技有興趣者)

- 不同貯存條件(溫度、包裝)對某食品褐變或腐敗速度的影響。
- 不同處理方式對食物中維生素 C 含量的影響(碘滴定法)。
- 自製食品(豆腐、優格、麵包)的配方變因實驗。

### E. 生物資訊 / 數理方向(適合會寫程式、愛數據者)

- 用公開生物資料庫(如 NCBI)查詢與比對某基因或蛋白質序列,做簡單分析。
- 用 Python / Excel 分析公開的生態調查資料、疫情資料或生物統計資料並視覺化。
- 模擬族群成長模型(如邏輯斯型成長),探討環境承載量。

> 生物資訊方向能同時展現「生物興趣」與「跨領域工具能力」,呼應 2026 年 AI + 生物的趨勢,但要注意說明你的生物學問題意識,不要做成純資工專題。

## 四、自主學習計畫的標準結構(可直接套用)

一份完整的生科自主學習計畫,建議包含:

1. **學習動機**:什麼經驗 / 觀察讓你想探究這個主題?(要具體、要是你自己的故事)
2. **學習目標**:你想回答什麼問題、學會什麼能力?(具體、可檢核)
3. **學習方法與進度**:分週 / 分月規劃。讀哪些書與文獻?做哪些實驗或觀察?訪談誰?
4. **預期成果**:研究報告、實驗數據、觀察日誌、心得文章等。
5. **執行紀錄**:過程中真實發生的事——包含卡關、調整、失敗。
6. **成果與反思**:你得到什麼結論?學到什麼?如果重來會怎麼改?這個主題如何連結到你想念的科系?

「高級中等學校自主學習網」收錄了大量依學群分類的優秀範例,可作為格式與深度的參考。

## 五、執行時的五個專業細節(讓教授眼睛一亮)

1. **設好對照組**:沒有對照組的「實驗」只是「體驗」。這是科學與非科學的分水嶺。
2. **重複測量**:至少做 3 次重複,並呈現平均與變異(標準差 / 誤差棒)。一次的結果不算數。
3. **量化記錄**:用數字、表格、圖表,不要只寫「長得比較好」。
4. **誠實寫限制**:樣本太少、變因控制不完美、器材精度不足——全部誠實寫出。這是科學誠實,是加分項。
5. **接觸一點英文資訊**:查文獻時刻意找一兩個英文科普來源或研究摘要,並在報告中說明你如何理解它。呼應生科系對英文閱讀的重視。

## 六、把自主學習「收斂」到你的目標科系

如果你已有明確的學類方向,讓自主學習主題與它呼應,能大幅提升「系所契合度」:

- 想念 **生命科學 / 生物科技系** → 分子、遺傳、微生物相關探究最對味。
- 想念 **食品科學系** → 食品微生物、加工、保存、品管相關。
- 想念 **生物資訊相關系** → 結合程式與生物資料的分析專題。
- 想念 **植物保護 / 生態相關** → 田野觀察、生物多樣性、植物病蟲害的長期記錄。

在自主學習成果的反思裡,明確寫一句:「這次探究讓我確認 / 修正了我對 OO 領域的興趣,也是我選擇貴系的原因之一。」——這條線索會把你的整份備審串成一個完整故事。
