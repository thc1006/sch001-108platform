ColleGo! 在生命科學學群列的多元能力是邏輯推理、主動學習、問題解決、數理科學、語文理解與表達、敏銳創造、快速知覺與總結，性格特質是主動積極、堅毅負責、探究冒險。生命科學學類的性格特質，前三名是堅毅負責、探究冒險，以及並列的主動積極與自信肯定。

## 各學類看重的課程與能力

生物資訊把數學和資訊科技排在生物前面，生醫工程排第一的是數學，生態在高中課程排第一的是國語文。下表的名次依 ColleGo! 列的百分比排。

| 學類 | 高中課程領域前三名 | 多元能力前兩名 |
|---|---|---|
| 生命科學 | 生物、化學、英語文 | 邏輯推理；主動學習 |
| 生物科技 | 生物、化學、英語文 | 邏輯推理；主動學習與問題解決並列第二 |
| 生化 | 化學與生物並列第一；英語文 | 邏輯推理與數理科學並列第一 |
| 生物資訊 | 數學、資訊科技；英語文與生物並列第三 | 程式設計；問題解決與數理科學並列第二 |
| 生醫工程 | 數學、物理、化學 | 數理科學；邏輯推理 |
| 植物保護 | 生物、化學、英語文 | 主動學習；肢體力量與協調 |
| 生態 | 國語文、生物、英語文 | 語文理解與表達；空間定向、邏輯推理、數理科學並列第二 |
| 食品生技 | 英語文、化學、生物 | 問題解決；語文理解與表達與數理科學並列第二 |

## 學類頁怎麼描述適合的人

ColleGo! 的生命科學學類頁寫，如果你喜歡觀察生命體的變化起伏，並且享受探究生命存在與行為展現的原因，這個學類很適合你。同一頁的「你所不知道的大學生活」寫，除了在實驗室工作，也可能到戶外做田野工作，要養成獨立思考、完成獨立研究的能力。

生物科技學類則說，研發實驗的過程會遇到變數，要不怕艱難挫折；如果喜歡把理論用在實務上，也喜歡和他人一起團隊合作，會喜歡這個學類。植物保護學類頁寫，要熱愛到田間野外採集、不怕熱、不怕累，才能適應野外調查。

## 六項能力怎麼在備審裡呈現

### 把好奇變成可以檢驗的問題

「我對基因很有興趣」和「我好奇同卵雙胞胎的指紋為什麼還是不一樣，想了解基因和發育環境怎麼一起作用」，後者讓人看得到你怎麼想問題。

在自述和專題報告裡寫出你的研究問題和假說。問題要具體、可以驗證，例如「某濃度的綠茶萃取物會不會影響大腸桿菌生長」。「我想研究癌症」就太大了。

### 懂變因、對照組和重複

在報告裡標出自變項、應變項、控制變項，說明對照組為什麼這樣設、做了幾次重複、為什麼是這個次數。實驗再簡單，把這些寫清楚，就看得出你懂實驗設計。

### 誠實寫限制和失敗

面試時教授會針對書審裡的專題問細節，例子見〈申請備審與面試要點〉的成大生科系面試。只寫成功的報告，經不起追問。

報告裡留一節「研究限制」，寫樣本數、變因控制、器材精度的問題。至少寫一次失敗，例如汙染、數據異常、假說被推翻，以及你怎麼找原因、怎麼修正。

### 讀英文科學資料

生命科學的新研究大多用英文發表，大學課程也常用英文教科書。在自述裡寫你讀英文科學資料的經驗，例如英文科普網站、某篇研究的摘要、靠翻譯工具讀完的一篇報導，再寫你從中理解了什麼。

### 數理、統計和程式

上面的表裡，生物資訊和生醫工程把數學排在生物前面。專題裡如果用 Excel 或 Python 整理、畫出數據，用平均、標準差這類基本統計說明結果，就寫出來。會用就寫，重點是用在對的地方。

### 具體的就讀動機

台大生科系的學習歷程自述把就讀動機、未來學習計畫單獨設題，成大生科系的面試也問過為什麼選生科、為什麼覺得自己適合，兩者都見〈申請備審與面試要點〉。查清楚你申請的系有哪些課、哪些實驗室、老師研究什麼，在自述裡連到你自己的經驗。例如某位老師研究的方向，正好和你專題裡的問題有關，就具體寫出來。

## 常見的寫法問題

1. 只有情懷：通篇寫熱愛生命，看不到任何提問或實驗。
2. 掛名：放了團隊海報，講不出自己負責哪一段、數據怎麼來。
3. 證書堆積：一排營隊和線上課程證書，每張都說不出收穫。
4. 完美無瑕：每個實驗一次成功、每個假說都成立，看起來不真實，也經不起面試追問。
5. 目標模糊：對申請的系不了解，動機換到任何一個生科系都能用。
