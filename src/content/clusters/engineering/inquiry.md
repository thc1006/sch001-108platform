## 題目從哪裡找

ColleGo! 每個學類頁都有「學類體驗」，列出可以先做做看的活動。下表挑出可以發展成探究或自主學習題目的幾項。

| 學類 | ColleGo! 建議的體驗 |
| :---- | :---- |
| 機械工程 | 根據所知的機械原理，手繪或用電腦繪圖畫一個機械產品；挑一項當紅技術，例如 3D 列印、自駕車、機器人，列出它需要的背景知識 |
| 電機工程 | 觀察身邊的電機電子產品，例如手機規格、電器的使用方法，想想有沒有改善的空間，提出疑問後找書、網頁或和別人討論 |
| 土木工程 | 觀察居住環境裡的建設，了解它的材料、機具、施工方式和人員工作內容，寫下自己的認識和疑問；依環境所需，設計規劃一個環境工程 |
| 材料工程 | 透過觀察記錄、分析數據、提出可能的假設，找出可信賴的答案；從專題學習和實驗操作了解技術能用在哪些領域 |
| 生醫工程 | 從生活中找問題，例如老人居家照護、醫院有哪些不便，再思考怎麼解決 |

日常觀察也能變成題目。一位臺北市非學校型態實驗教育（自學）的高中生，2023 年在美國國際科技展覽會（ISEF）數學類得到三等獎。作品摘要寫，研究動機是在浴室看著地上的積水，想像空中有一面曲面鏡：光束射向它，在什麼情況下能一直往前反射？作者把反射過程寫成動態系統，找出曲線要滿足的充分條件。

## 大學怎麼看自主學習與探究成果

教育部與招聯會 2021 年 4 月的簡報〈學習歷程、備審資料與大學選才〉寫，自主學習計畫成果看的是主動學習的能力、時間安排與規劃的能力，計畫主題和學系領域不一定要相關。同一份簡報引台灣物理學會的意見：課程學習成果重視探究的過程，包括發現與定義問題、設計探究方法、分析成果、組織呈現與反思；不一定要是小論文或科展作品，自己彙整、歸納及反思的筆記也可以。

各系的要求仍有不同。清大工學院學士班 115 學年度的準備指引寫，多元表現採計高中自主學習計畫與成果時，「審查著重自主學習歷程」。成大資工對課程學習成果怎麼呈現的要求，詳見〈申請備審與面試要點〉。

## 一份自主學習報告的例子

草屯商工一位二年級學生在南投縣 112-2 自主學習聯合成果發表會，報告自學 3D 列印的過程。這位同學做第三件作品桌牌時，列印前發現浮雕字體和桌牌的斜面對不上，於是「開始利用先前所學的『畢氏定理』嘗試去計算角度，與數學領域做結合」。報告分動機與規劃、過程與成品、心得與反思、未來的期許四部分，三件作品各寫了想做的原因、遭遇的困難和解決方法。
