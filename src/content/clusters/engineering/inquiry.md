## 好題目長什麼樣子

工程的探究專題不用追求大題目。好題目通常有四個條件：從真實的觀察出發、範圍小到做得完、用得上學過的學科知識、有動手做的部分。

## 五個選題方向

| 方向 | 怎麼做 | 例子 |
| :---- | :---- | :---- |
| 日常現象探究 | 從生活裡的物理、化學現象出發，走完觀察、假設、實驗、驗證一輪。題目大小不要緊，過程要完整 | 光線反射的軌跡、某種材料受力後的變形、家電的耗電量 |
| 解決真實問題 | 找家裡、學校或社區的一個不便，做出裝置並實際測試。聚焦在一個使用者的需求，功能不用多 | 自動澆水系統、居家偵測裝置、輔助長輩或身障者的小工具 |
| 逆向工程 | 拆一台家電或裝置，記錄結構和運作原理，推測工程師為什麼這樣設計，例如考量成本、製造方式或功能，最後寫成分析報告 | 舊電風扇、烤麵包機、壞掉的玩具 |
| Arduino、Raspberry Pi | 從零做出一個有具體用途的裝置，記下用了哪些元件、電路怎麼接、怎麼除錯。只讓 LED 閃爍還不夠，要能解決一個問題 | 教室溫濕度記錄器、忘記關燈提醒器 |
| 程式與數據 | 替自己或社團寫網站、App 或小程式，或分析一組真實數據。程式碼放上 GitHub，在學習歷程附連結 | 社團報名表、用政府開放資料畫出空氣品質變化 |

拆家電之前先拔插頭。微波爐、舊型映像管電視這類裡面有高壓電容的電器，拔了插頭仍可能電人，不要拆。

日常觀察也能做到國際科展。一位臺北市的自學生，2023 年在美國國際科技展覽會（ISEF）數學類得到三等獎。作品摘要寫，他在浴室看著地上的積水，想像空中有一面曲面鏡：光束射向它，在什麼情況下能一直往前反射？他把反射過程寫成動態系統，找出曲線要滿足的充分條件。

ColleGo! 每個學類頁都有「學類體驗」，列出可以先做做看的活動。下表挑出可以發展成題目的幾項。

| 學類 | ColleGo! 建議的體驗 |
| :---- | :---- |
| 機械工程 | 根據所知的機械原理，手繪或用電腦繪圖畫一個機械產品；挑一項當紅技術，例如 3D 列印、自駕車、機器人，列出它需要的背景知識 |
| 電機工程 | 觀察身邊的電機電子產品，例如手機規格、電器的使用方法，想想有沒有改善的空間，提出疑問後找書、網頁或和別人討論 |
| 土木工程 | 觀察居住環境裡的建設，了解它的材料、機具、施工方式和人員工作內容，寫下自己的認識和疑問；依環境所需，設計規劃一個環境工程 |
| 材料工程 | 透過觀察記錄、分析數據、提出可能的假設，找出可信賴的答案；從專題學習和實驗操作了解技術能用在哪些領域 |
| 生醫工程 | 從生活中找問題，例如老人居家照護、醫院有哪些不便，再思考怎麼解決 |

## 把好奇心縮成一個探究問題

一開始的好奇通常很模糊，例如「為什麼冷氣這麼耗電」。照下面五步，把它縮成做得完的專題：

1. 記錄觀察：隨手記下「為什麼會這樣」的時刻，手機備忘錄就夠。
2. 縮小範圍：把大問題切成幾週到幾個月內、用手邊資源驗證得了的小問題，例如「冷氣設定溫度每調高 1 度，我房間一晚的用電差多少」。
3. 寫出可以驗證的假設：一句話寫出你預期的結果，而且要能用實驗或實作檢驗。
4. 規劃方法：決定要觀察、測量、比較什麼，用什麼工具，量幾次。
5. 預想結果和限制：先想可能的結果，也想方法的弱點，例如樣本太少、量測工具不夠準。

## 自主學習計畫怎麼寫

自主學習計畫要寫清楚三件事：目標是什麼、過程做了什麼、做完學到什麼。自學一項工具也可以當計畫，例如用 Coursera、edX、YouTube 上的課學 Python 或電腦繪圖軟體，再拿來做一件小作品。

一位高職生自學 3D 列印，做桌牌時發現浮雕字和桌牌的斜面對不上，就用學過的畢氏定理算出角度。他的報告分成動機與規劃、過程與成品、心得與反思、未來的期許四段，三件作品各寫了想做的原因、遇到的困難和解決方法。這個分段方式可以直接拿來用。

## 大學怎麼看自主學習與探究成果

教育部和招聯會給高中的簡報寫，自主學習計畫成果看的是主動學習的能力、時間安排與規劃的能力，計畫主題和學系領域不一定要相關。同一份簡報引台灣物理學會的意見：課程學習成果重視探究的過程，包括發現與定義問題、設計探究方法、分析成果、組織呈現與反思；不一定要是小論文或科展作品，自己彙整、歸納及反思的筆記也可以。

各系的要求仍有不同。清大工學院學士班 115 學年度的準備指引寫，多元表現採計高中自主學習計畫與成果時，「審查著重自主學習歷程」。成大資工對課程學習成果怎麼呈現的要求，見〈申請備審與面試要點〉。

## 專題報告怎麼呈現

- 寫出完整過程，不要只有結論。遇到哪些問題、失敗之後怎麼改，都要寫。
- 用圖表和照片，讓讀的人看得到你做了什麼。
- 團隊專題要寫清楚哪部分是你做的、你負責什麼。
- 誠實寫出方法的限制，以及下一次會怎麼改。
