任何一項活動的「價值」並非與生俱來，而是透過你的實際參與、深度反思，以及把它與工程師核心職能連結的能力創造出來的。即使是看似無關的經歷，只要經過適當詮釋與轉化，也能成為申請文件中的有力武器。這一頁帶你規劃高影響力的多元表現。

## 競賽地圖：四種競賽，四種能力

不同競賽被設計用來測試不同的技能組合。策略性地選擇參與，能建立一個更全面且具說服力的個人檔案。

| 競賽類型 | 核心焦點 | 關鍵能力展現 | 代表性競賽 |
| :---- | :---- | :---- | :---- |
| 科學探究型 | 科學方法、研究深度、原創性 | 深入探究、數據分析、學術表達 | 臺灣國際科學展覽會（TISF） |
| 系統整合型 | 團隊合作、系統整合、專案管理 | 跨領域協作、工程設計、抗壓性 | FIRST 機器人競賽（FRC）、生活科技學藝競賽 |
| 應用設計型 | 解決真實問題、創意、技術應用 | 需求洞察、創新、軟硬整合 | 全國高中職電資創意應用競賽 |
| 程式檢定／競賽 | 邏輯推理、演算法、問題拆解 | 客觀程式能力證明 | APCS、NPSC、黑客松、CTF |

### 科學探究：臺灣國際科學展覽會（TISF）

TISF 的核心在於展現遵循科學方法進行深度探究的能力。得獎作品主題橫跨純數理論、尖端生物化學、實用輔助科技，評審高度重視研究的深度、嚴謹性與原創性。

TISF 的國際規模持續擴大：**2026 年舉辦的第 24 屆 TISF，吸引來自 32 個國家與地區、共 667 位師生參與，233 件作品晉級決賽**，已是全球最具指標性的科展之一。對參賽者而言，過程本身就是最寶貴的收穫——指導教授形容參與科展是一個「知識重整的過程」，迫使學生跳脫死背、真正消化並應用知識。

### 系統挑戰：FRC 機器人競賽

FRC 機器人競賽更像一場「微型創業」的演練。參賽隊伍不僅要設計、製造重達數十公斤的工業級機器人，還必須在緊迫時限內進行資金募集、團隊管理與市場行銷，運作模式被形容為一家「小型公司」。

FRC 每年 1 月公布全新賽季任務——**2026 賽季主題為「REBUILT presented by Haas」，於 2026 年 1 月 10 日全球同步揭曉**，隊伍需在約六週內完成機器人設計與製造。台灣參賽風氣興盛，建國中學、北一女中、麗山高中、嘉義竹崎高中等多支隊伍近年皆遠征美國各區域賽與休士頓世界總決賽，並屢獲「卓越影響力獎」、「卓越工程獎」等獎項。FRC 能完美對應教授腦中的「職能矩陣」，全面涵蓋技術整合、團隊合作、壓力下解決問題與溝通協調。

### 應用設計：電資創意應用競賽與生活科技學藝競賽

「全國高中職電資創意應用競賽」評估學生辨識真實問題並設計創新解方的能力。得獎作品高度聚焦「智慧化」科技與物聯網（IoT），從智慧居家食物補給站到旋轉稜鏡式 3D 光達不一而足，顯示教授欣賞能掌握當前科技趨勢並創造性應用的學生。

「生活科技學藝競賽」則鼓勵學生「解決生活中所發掘之問題」，評分標準特別看重「製作自製程度」，直接衡量把創意轉化為實體原型的動手能力。

### 程式競賽與黑客松

APCS 是程式能力的客觀指標（詳見「科系風向標」一頁的改制說明）。黑客松（Hackathon）則是在極度時間壓力下進行的協作開發挑戰，能有效展現創造力、團隊合作與快速原型開發能力。台灣的梅竹黑客松、中學生黑客松等都是值得參與的舞台。特殊選才管道尤其看重在這些領域有卓越表現的學生。

### 科學辯論：臺灣青年學生物理辯論競賽（TYPT）

TYPT 是一項獨特的競賽，要求隊伍花費近一年研究開放性物理問題，並以全英語進行正式學術辯論。它能同時展現深度科學探究、實驗設計、邏輯論證與高階英語溝通能力，對志在國際舞台的未來工程師而言極具鑑別度。

## 好奇心工作坊：自主專案與創客精神

相較於組織性競賽，自主專案更能突顯個人的熱情、好奇心與自學能力。

- **從零到一的創造（Arduino、Raspberry Pi、3D 列印）**：運用開源平台進行個人專案開發，是展現自驅力與實務解題能力的最佳證據。一份記錄完整的 Arduino 專案——包含程式碼、電路圖、遇到的挑戰與最終成果——是極具說服力的材料。曾有清華大學錄取生以從零自造「WiFiBoy」遊戲機、從一個想法做到參加國際展覽的完整創客旅程，完美體現這種精神。
- **逆向工程（拆解家電）**：把拆解家電的過程系統性記錄下來，不只是滿足好奇心，更可被詮釋為對機械與電子原理的「系統性分析」。建議撰寫一份分析報告，針對產品設計提出假設，例如工程師為何做出某些設計決策（考量成本、製造工藝或功能）。
- **個人程式開發專案**：為了滿足個人或社群需求而開發網站、App 或腳本，能直接證明你運用技能創造價值的能力。把專案放上 GitHub 並附連結，已是展現程式能力的標準做法。

## 非典型活動的工程關聯性

許多看似與工程無關的活動，若深入挖掘其內涵，同樣能展現工程師所需的關鍵特質：

- **實務服務（修繕校內設施）**：可詮釋為「在資源有限環境下的應用問題解決」，展現主動性、實用技能，以及診斷並修復真實系統的能力。
- **耐力運動（鐵人三項）**：是長週期工程專案的絕佳隱喻。所展現的紀律、毅力、目標設定、訓練中的數據分析、克服撞牆期的韌性，都直接對應教授重視的「正向人格特質」與「抗壓性」。
- **跨領域領導與協作**：即使在非理工社團擔任領導者也有高度價值。管理團隊、規劃預算、解決衝突、傳達願景，都是工程專案管理不可或缺的通用技能。

## 活動與敘事策略對應表

| 活動類別 | 具體範例 | 敘事策略重點 |
| :---- | :---- | :---- |
| 組織性競賽 | FRC 機器人 | 聚焦團隊克服的某個具體技術或人際挑戰，詳述你的貢獻 |
| 程式競賽 | APCS／程式設計競賽 | 除了分數，反思一個特別困難的題目與你的思考過程 |
| 科學辯論 | TYPT | 強調長達一年的研究過程與英語辯論中如何應對質疑 |
| 自主專案 | Arduino／RPi 專案 | 用照片影片記錄過程，強調「除錯的旅程」而非僅展示成品 |
| 自主專案 | 逆向工程 | 撰寫分析報告，對產品設計決策提出假設 |
| 非典型活動 | 耐力運動 | 視為長週期專案敘述，討論如何用數據優化、培養心理素質 |
| 非典型活動 | 實務服務 | 記錄一個修繕的「案例分析」：問題、診斷、限制、成果 |

## 關鍵元技能：專案的記錄與呈現

在準備這些活動時，一個關鍵的「元技能」是專案的記錄與呈現。優秀的學習歷程範例之所以受讚賞，往往因為「呈現清楚明瞭、善用圖表」。技術寫作、數據視覺化、公開演說，已不再是次要的軟實力，而是把專案價值最大化的關鍵技能。**一個記錄完善的普通專案，影響力可能遠大於一個記錄拙劣的卓越專案。**

## 避雷指南：多元表現最常見的地雷

- **地雷一：以量取勝。** 蜻蜓點水式的活動清單沒有意義。一份記錄詳實、反思深刻的個人專案，價值遠勝十張營隊參與證明。
- **地雷二：只列活動名稱、不談內涵。** 單純寫「參加 XX 大學電機營」是無效的。必須具體闡述遇到什麼困難、產生什麼興趣、如何堅定申請決心。
- **地雷三：只展示成品、隱藏過程。** 教授想看的是「除錯的旅程」——那些失敗的嘗試與逐步改進。隱藏過程反而讓檔案顯得不真實。
- **地雷四：經歷之間各自獨立、沒有連結。** 不要假設教授會自行領會。你必須主動為每段經歷與目標科系建立連結。
- **地雷五：盲目追求「響亮」的活動。** 關鍵不在活動本身的名氣，而在你如何詮釋與連結。真實的好奇心驅動，永遠勝過為了履歷而參加的昂貴制式營隊。
