本頁的件數、指引與分則都是 115 學年度的資料，116 學年度以甄選會公告的簡章和各系當年度的指引為準。

## 審查資料

甄選會 115 學年度的上傳系統操作手冊寫，審查資料分為修課紀錄、課程學習成果、多元表現、學習歷程自述及其他五大項；從學習歷程中央資料庫勾選時，課程學習成果至多 3 件，多元表現至多 10 件，超過系統就不能儲存。教育部大學多元入學升學網的常見問題寫，課程學習成果「不一定要交滿3件，有好的1件就足夠了」，大學更重視成果的發展歷程、心得與反思。

每個系要的資料和看的重點不同，要看該系當年度的審查資料準備指引。以下是成大資工（含智慧系統實作組）與清大工學院學士班 115 學年度的指引：

| 學系 | 準備指引寫的 |
| :---- | :---- |
| 成大資訊工程學系 | 修課紀錄著重數學、英語文、資訊科技；課程學習成果要讓人看懂學習過程，包括主題的訂定、資料的收集、遇到問題如何解決，「請勿單純貼上資料後繳交」；多元表現問「曾遭遇最大的困難或挑戰是什麼？如何調整心態面對難關？如何制定策略及方法解決問題？」 |
| 成大資工智慧系統實作組 | 同上，另以資訊科技專案實作紀錄為重點，要提供 GitHub 連結；專案「並非修課或解題等作業等級者，須以解決某一問題為目標」 |
| 清大工學院學士班 | 進大學後再選領域做跨領域規劃，適合「興趣多元，具有創新想法及具備領導統籌能力的學生」；多元表現綜整心得至多 800 字、3 張圖片，三題分別問正面影響他人或對團體有貢獻的經驗、面對困難時的堅毅、規劃統籌能力；用生成式 AI 協助準備時，要保存手稿、筆記或提示紀錄等原始資料備查 |

## 學習歷程自述

教育部高等教育司委託台大社會系作伙學團隊編的《學習歷程 大學申請入學第二階段準備指南》，整理了三種學習歷程自述的寫法：以故事串連經驗並在段落加小標題、照時間順序寫、以能力分類再說明經驗。書中的示例有一位申請材料工程學系的同學，在一頁篇幅內用小標題整理高中三年的成長；另一位申請光電工程學系的同學，在多元表現綜整心得裡用自己具備的能力當小標題，再說明是哪些經歷養成的。

同一本指南回答小組作品怎麼呈現：在學習歷程自述或多元表現綜整心得說明自己扮演的角色、收穫、解決的困難與方法，也要充分熟悉小組作品，面試時才答得出來。

## 筆試

有些校系第二階段考筆試。以台大工學院四個系與電資學院的電機系 115 學年度的校系分則為例：

| 學系 | 筆試 | 佔甄選總成績 |
| :---- | :---- | :---- |
| 土木、機械 | 綜合筆試（A）：數學、物理，工學院 A 組共同試題 | 30% |
| 化工、材料 | 綜合筆試（B）：物理、化學，工學院 B 組共同試題 | 30% |
| 電機 | 數學筆試、物理筆試；數學筆試用電資學院共同試題，同時報考電機、資工（含 APCS 組）的，成績分送兩系 | 各 15% |

台大電機的分則另寫，筆試二科總和成績一般生在前 235 名的，才給書面審查成績。清大資工甲組與陽明交大資工甲組也考筆試，各佔 10%。

## 面試

作伙學的指南寫，有些教授會在面試中確認審查資料的真實性，針對作品詢問學習的動機、過程、遇到的困難和反思，熟讀自己的檔案，面試會更順利。

特殊選才是申請入學以外的另一個管道。一位學生在 HackMD 記下 113 學年度清大資工特殊選才的面試：教授出一題運算式字串的題目，他用 linked list 和遞迴解，教授說「你的解法是對的，是跟我們的解法一樣好的，但這題其實用 stack 就好」，接著說明 stack 的作法。
