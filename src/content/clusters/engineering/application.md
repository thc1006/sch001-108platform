# 工程學群申請備審與面試要點

擁有豐富經歷只是第一步，如何把這些經歷編織成一個引人入勝且具說服力的故事，才是致勝關鍵。成功的申請者，往往把整份申請文件視為他們的第一個、也是最重要的工程設計專案。這一頁帶你從備審結構走到面試現場。

## 把申請文件當成一個工程設計專案

把整份申請文件視為一個工程設計專案，意味著你需要：分析「使用者需求」（大學的選才標準）、管理「專案資源」（自身的經歷與產出），並在「規格限制」（字數、上傳件數）內，設計並交付一個最佳化的「產品」（申請文件）。這種心態本身，就是工程師思維的最佳展現。

## 備審資料的結構

學習歷程檔案的結構本身就導向一種側重敘事與質性分析的評估模式。以 115 學年度（2026 年）申請入學為例，第二階段審查時你需要從學習歷程資料庫中勾選：

- **課程學習成果**：至多 3 件。優先呈現「探究與實作」「自主學習」等能展現完整探究循環的成果。
- **多元表現**：至多 10 件。涵蓋競賽、社團、幹部、自主專案、服務學習等。
- **綜整心得與學習歷程自述**：串連所有證據的「黏著劑」。

件數有限，正凸顯「重質不重量」的選材精神。挑選原則是：每一件都要能在教授腦中的「職能矩陣」上補上一塊拼圖，並且彼此能串成一個有邏輯的成長故事。

## 學習歷程自述：串連一切的核心

「學習歷程自述」扮演至關重要的角色。它是你串連所有證據——從修課紀錄的成績、課程學習成果的專案，到多元表現的活動——的黏著劑。它讓審查教授看見一個立體的、會思考、會反省的個體，而不只是數據的集合。撰寫自述時，掌握以下四項原則。

### 原則一：用 STAR 敘事框架

僅僅羅列活動是遠遠不夠的，深度反思才能賦予經歷意義。建議採用工程師版的 STAR 原則：

- **S（Situation 情境）**：描述活動的背景與脈絡。
- **T（Task 任務）**：說明你在此情境下的具體目標或挑戰。
- **A（Action 行動）**：詳細闡述你為達成目標所採取的**具體行動**——這是展現個人貢獻與能力的關鍵。
- **R（Result 結果）**：說明行動帶來的成果，不只包括成功，更重要的是從失敗中學到的教訓與個人成長。

舉例：與其平鋪直敘「我贏了機器人比賽」，不如這樣寫——「在一個高壓的競賽情境下（S），我們團隊的任務是設計一個全新的舉升機構（T）。我主動學習了一款新的 CAD 軟體並製作了三種原型（A），最終我們的設計贏得評審獎，也讓我深刻體會快速迭代的重要性（R）。」

### 原則二：展示，而非陳述

與其空泛宣稱「我具備解決問題的能力」，不如具體描述你在 Arduino 專案中遇到的一個棘手錯誤，以及你如何透過系統化邏輯推理最終定位並修復它。用具體實例，讓你的能力鮮活起來。

### 原則三：反思過程，而不僅是結果

備審資料應著重呈現整個專案的「旅程」，而不僅是最終成果。過程中遇到哪些挑戰？從失敗中學到什麼？這個專案如何改變了你的觀點？這些反思能展現你的成熟度與深度思考能力。

### 原則四：主動為教授串起線索

不要假設教授會自行領會你的經歷與科系之間的關聯。你必須明確說明——例如，一個非技術性社團的領導經驗，如何培養了適用於工程領域的專案管理技能。一個高效策略是，在反思中使用目標科系教育目標裡的關鍵詞彙，例如「這次經歷直接強化了我『設計與執行實驗』的能力」。

## 建立可驗證的作品集

「展示，而非僅僅陳述」是最高原則。與其說你建造了一台機器人，不如附上原型照片、運作影片連結，甚至一段關鍵程式碼。

對於任何程式設計相關的活動，一個維護良好的 GitHub 個人頁面已是黃金標準——它提供了程式能力的鐵證，也記錄了專案的演進與協作歷史。成功大學資工系的「多元表現」準備指引就特別要求提供「資訊科技專案實作紀錄」的 GitHub 連結，並強調專案需以「解決某一問題為目標」。

## 面試準備要點

工程學群的面試（第二階段甄試）是備審資料的延伸。準備時掌握以下重點：

- **熟悉自己的備審內容**：面試官的提問多半從你的學習歷程出發。每一個你寫進檔案的專案，都要能清楚講出「為什麼做、怎麼做、學到什麼」。
- **準備好談「失敗」**：教授很可能直接問你「曾遭遇最大的困難或挑戰是什麼」。誠實、有條理地描述一個技術難題或心理困境，並聚焦於你如何分析、嘗試、修正與堅持。坦然面對失敗，反而會增強你敘述的真實性與說服力。
- **對更優解法保持開放態度**：曾有特殊選才錄取生在面試中向教授解釋自己的解法後，教授指出一個更簡潔高效的方法（使用 Stack）。這位學生把這段經歷納入心得，展現了樂於學習新知的開放態度——這正是科學精神的重要一環。面試中若教授提出不同看法，展現開放與思考，比硬辯更有價值。
- **連結未來**：整個敘事必須具有前瞻性。不僅說明你「做了什麼」，更要闡述這些經歷如何為你申請的特定科系與未來職涯目標做好準備。
- **了解目標科系的調性**：台大重研究深度、清大重跨域創新、陽明交大重產業趨勢、成大重務實實作。面試前先了解目標科系的價值觀，讓回答更貼合。

## 申請時程規劃（115 學年度參考）

工程學群申請是一場長期專案，建議及早規劃：

- **高一至高二**：累積探究專題與自主學習成果；參與競賽（FRC 賽季每年 1 月公布、APCS 每年 6 次檢測）。APCS 成績三年內有效，可及早應試、保留最佳成績。
- **高三上學期**：完成並上傳課程學習成果；持續累積多元表現。
- **學測後**：依學測成績選填志願；準備第二階段所需的勾選件數、綜整心得與自述。
- **第二階段甄試**：依各校系公告日期，準備書面審查、筆試（部分校系如台大含數理筆試）與面試。

實際日程以大學甄選入學委員會公告的 115 學年度招生簡章為準。

## 真實性，永遠是最高原則

一份最強而有力的申請文件，是任何人都無法複製的，因為它真實地、獨一無二地屬於你自己。審查教授擁有豐富經驗，能輕易分辨源於真實熱情的探索與僅為「填充履歷」的活動。最終目標不應是打造一份紙面上完美的資料，而是去追尋那些真正讓你著迷的事物，並學會用工程的語言闡述這份熱情。
