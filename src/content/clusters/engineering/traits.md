這一頁從台大機械系、清大動機系的教育目標，整理工程學群的核心特質與能力，再列出可以拿來當證據的經歷。

## 教育目標裡的共通原則

本站從台大機械系的教育目標與清大動機系的課程介紹，整理出三項原則。

### 核心原則一：理論與實踐的統合

工程學應用科學原理解決實際問題。台大機械系的教育目標明確指出，要培養學生「具備學理基礎及應用工程知識與技術之能力」。清大動機系大四必修的專題實作課程，要學生選定專題研究題目，藉由實際設計與實驗操作解決工程問題，正是此理念的體現。

### 核心原則二：從發現問題到解決問題

工程師要解決問題，也要能發現、定義問題。台大機械系的教育目標寫的是培養「發掘、分析、解釋、處理問題之能力」，不只處理別人給的題目。

### 核心原則三：團隊合作與跨領域思維

現代工程挑戰的複雜性使得單打獨鬥不復存在。清大動機系的專題課程明確要求「團隊合作」，其研究範疇更整合了機械、電機、AI、生醫等多重領域。未來的工程師必須能在團隊中協作，並整合不同領域知識以達成共同目標。

準備申請文件時，可以拿這三項原則檢查：你的經歷能不能呈現理論與實作的結合、發掘問題的能力、團隊合作。

## 硬實力與軟實力

本站把工程學群需要的能力分成硬實力與軟實力兩張表，並列出可以拿來當證據的經歷。從修課紀錄到多元表現，申請文件最好在每一類都有具體的例子。

### 硬實力：你會做什麼

| 關鍵能力 | 具體技能／工具 | 可採用的「證據」 |
| :---- | :---- | :---- |
| 程式設計 | Python、C/C++ | APCS 檢定成績、NPSC／資訊奧林匹亞等競賽、活躍的 GitHub 帳號 |
| 數位製造 | 3D CAD、3D 列印 | 完整呈現「概念草圖→CAD 建模→列印原型→成品測試」的專案報告 |
| 軟硬整合 | Arduino、Raspberry Pi、感測器 | 打造解決特定問題的裝置（如自動澆水系統），詳述元件與電路 |
| 電子量測 | 示波器、萬用電表 | 專題報告中的分析章節，展現超越「組裝」的「分析」能力 |

### 軟實力：你如何做事

| 關鍵能力 | 具體展現 | 可採用的「證據」 |
| :---- | :---- | :---- |
| 問題解決 | 系統性除錯、邏輯分析 | 以 STAR 原則描述一個卡關的專案，重點在你的分析與行動 |
| 團隊合作 | 分工協作、溝通 | 大型團隊競賽經驗（如 FRC）、黑客松的高壓快速協作 |
| 溝通表達 | 技術寫作、公開演說 | 排版良好、圖文並茂的專題報告或 GitHub README；科學辯論 |
| 自主學習 | 規劃執行、資源探索 | 目標明確、反思深刻的自主學習計畫；好奇心驅動的個人專案 |
| 毅力與韌性 | 長期投入、挫折復原力 | 持續一年以上的長期專案；克服困難的具體敘事 |

## 智識好奇心：所有能力的底層驅動力

所有上述職能的底層驅動力，是對知識的「智識好奇心」(Intellectual Curiosity)。審查指引中反覆強調的「動機」，正是對此的探問。

相較於僅為豐富履歷而參加的活動，一個源於好奇心的項目（例如因為好奇烤麵包機的加熱原理而把它拆解分析）更能展現自主學習的內在驅動力。在變化快速的工程領域，這種好奇心也是持續自學的動力。

## 備審資料常見的扣分寫法

準備時可以避開下面四種寫法：

- **只說有熱情，沒有證據。** 空泛的形容詞沒有說服力。「我對寫程式充滿熱情」這句話，不如「我為了自造一台能玩遊戲的掌機，從國中開始摸索 Arduino，帶著它去日本、美國的創客展，根據使用者回饋改進了三個版本」具體。熱情要落在你投入的時間與克服的困難上。

- **只寫成功，不寫失敗。** 完美無瑕的紀錄反而不真實。成功大學資工系的備審資料準備指引直接問：「曾遭遇最大的困難或挑戰是什麼？」一份詳述 3D 列印模型為何翹曲、如何調整底盤溫度與黏著劑解決的報告，更能呈現你的韌性。

- **經歷各自獨立，沒有串起來。** 你參加了機器人社、考了 APCS、又跑了鐵人三項，這三件事有什麼關聯，要由你自己說明。例如：機器人社讓你發現對控制系統有興趣，於是準備 APCS；鐵人三項則讓你學會像管理長期工程專案一樣有紀律地規劃。

- **看不出是自己想做的。** 出於好奇心的探索，和為了填履歷而參加的活動，寫出來的細節不一樣。一個因為好奇而拆解烤麵包機的學生，能寫的過程與發現，通常比參加一個制式營隊多。

## 工程倫理與品格

台大機械系的教育目標包含「培養學生端正品行、健全人格、熱心服務及重視專業倫理」。不少創意競賽的得獎作品也有明確的社會用途（如為身障人士設計輔助科技、關注環境永續的設計），題目的選擇本身就反映了學生的價值觀。

準備時，除了個人的技術成果，也可以寫團隊合作、溝通，以及你怎麼想一件工作「為何而做」。
