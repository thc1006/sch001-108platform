## ColleGo! 列的能力與特質

ColleGo! 在工程學群列的多元能力是數理科學、邏輯推理、主動學習、程式設計、問題解決、語文理解與表達、運作分析、機械操作，性格特質是主動積極、堅毅負責、合作互助。

各學類看重的地方不一樣。下表列出 ColleGo! 各學類最看重的前三名，依序排列。

| 學類 | 高中課程領域 | 多元能力 | 性格特質 |
| :---- | :---- | :---- | :---- |
| 機械工程 | 數學、物理、英語文 | 數理科學、機械操作、問題解決 | 堅毅負責，主動積極與變通開創並列第二 |
| 電機工程 | 數學、物理、英語文 | 數理科學、邏輯推理、程式設計 | 堅毅負責、主動積極、探究冒險 |
| 土木工程 | 數學、物理、英語文 | 數理科學、主動學習、邏輯推理 | 主動積極、堅毅負責、探究冒險 |
| 化學工程 | 物理、數學、化學 | 數理科學、邏輯推理、問題解決 | 堅毅負責、主動積極、合作互助 |
| 材料工程 | 物理、化學、數學 | 數理科學、邏輯推理、問題解決 | 主動積極、堅毅負責、合作互助 |
| 生醫工程 | 數學、物理、化學 | 數理科學、邏輯推理、程式設計 | 合作互助、堅毅負責、探究冒險 |
| 資訊工程 | 資訊科技、數學、英語文 | 程式設計、數理科學、邏輯推理 | 堅毅負責、主動積極、變通開創 |

機械工程學類頁另外寫，適合的人喜愛動手做、探究原理的成因，善於理解圖形與空間關係。頁面也寫，機械系課程著重硬體，要融會貫通還得延伸學習程式語言與電子電路；團體報告的機會也多，團隊合作是學習的一環。

## 每種能力可以拿什麼證明

會做什麼：

| 能力 | 工具 | 可以當證據的東西 |
| :---- | :---- | :---- |
| 程式設計 | Python、C/C++ | APCS 成績、資訊相關競賽、GitHub 上的專案 |
| 數位製造 | 電腦繪圖（CAD）、3D 列印 | 一份從概念草圖、CAD 建模、列印原型到成品測試的專案報告 |
| 軟硬整合 | Arduino、Raspberry Pi、感測器 | 一個解決特定問題的裝置，例如自動澆水系統，寫出用了哪些元件、電路怎麼接 |
| 電子量測 | 三用電表、示波器 | 專題報告裡的量測與分析，說明數據代表什麼，組裝之外還要能分析 |

怎麼做事：

| 能力 | 具體表現 | 可以當證據的東西 |
| :---- | :---- | :---- |
| 問題解決 | 有系統地除錯、推理 | 用 STAR 寫一個卡關的專案，重點放在你怎麼分析、做了什麼 |
| 團隊合作 | 分工、溝通 | FRC、生活科技學藝競賽這類團隊競賽，寫清楚你負責的部分 |
| 溝通表達 | 技術寫作、上台報告 | 圖文清楚的專題報告、GitHub 的 README、科學辯論 |
| 自主學習 | 規劃、找資源 | 目標明確、有反思的自主學習計畫，或因為好奇自己做的專案 |
| 毅力 | 長期投入、遇到挫折還繼續做 | 做了一年以上的專案，以及克服困難的具體經過 |

## 寫備審時的四個提醒

- 熱情要用做過的事證明。「我對寫程式充滿熱情」這句話沒有說服力，寫你為了什麼目標自學了什麼、做出了什麼。
- 失敗可以寫。例如 3D 列印的模型翹曲，你怎麼查原因、調整平台溫度或加黏著劑之後解決，比只放成品更看得出能力。
- 經歷之間的關係要自己寫出來。例如機器人社讓你對控制系統有興趣，於是去考 APCS；長跑讓你學會照計畫練習，做長期專案也用得上。
- 做自己真的有興趣的事。為了填備審而參加的活動，寫出來很難有內容。

## 台大機械系的教育目標

台大機械系 2004 年修訂教育目標，列了七項細部目標，包括培養學生「具備學理基礎及應用工程知識與技術之能力」，訓練學生「具備設計與執行實驗，以及發掘、分析、解釋、處理問題之能力」，培養「團隊合作之精神，訓練表達溝通、及領導與管理之能力」，以及「端正品行、健全人格、熱心服務及重視專業倫理」。

## 清大動機系給高中生的準備方向

清大動機系在 ColleGo! 寫，系上的學習方法強調理論與實作結合，例如大四必修的專題實作課程，要選定題目、和他人團隊合作，藉由實際設計與實驗操作解決工程問題。系上的學生團隊有自己設計製造方程式賽車的清大賽車工廠，以及參加國內外機器人比賽的 DIT Robotics。

同一頁列了高中階段可以準備的方向：

1. 培養主動發掘問題並解決問題的能力。
2. 利用所學知識，把理論用在實際應用。
3. 在任何學習過程中都能反思。
4. 融入團隊合作，發揮自我價值。
5. 提升英文能力。
