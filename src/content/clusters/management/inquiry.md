親子天下的整理寫，自主學習計畫沒有規定格式，架構清楚展現學習主題、目標、內容、時數和方法就可以；對主題沒有想法，可以參照志願校系的備審指引找方向。計畫失敗也可以寫，說清楚看出哪些問題、怎麼改進，就是完整的自主學習歷程。站上的[自主學習計畫範本](../../../autonomous-learning/plan-templates.html)可以直接套用。

## 校系怎麼看

台大企管組和政大企管 115 學年度的準備指引都寫「具體說明自主學習計畫之收穫與反思」。成大企管問的是有什麼專長、怎麼發掘、怎麼發展，以及和企業管理領域有什麼連結。陽明交大管理科學系要「展現自主研究動機、過程中解決困難的學習力及如何改進反思」。中興企管和東吳企管的多元表現沒有列自主學習計畫與成果。

課程學習成果方面，成大企管「著重在語言類、數學類、邏輯推理的學習成果，或相關領域書面報告」；中興企管採計書面報告、實作作品和社會領域探究活動成果，要和學系相關。自主學習常見的缺失，見〈多元表現亮點策略〉的十個地雷。

## 題目從哪裡來

ColleGo! 各學類頁的「學類體驗」列了高中可以先做的事，下表各舉幾項：

| 學類 | ColleGo! 建議的體驗 |
|---|---|
| 企業管理 | 分析某個組織或產品的市場狀況，完成一份商業調查簡報；擔任組長或幹部帶活動；學好機率統計、微積分 |
| 國際企業 | 從報章雜誌和網路接觸新資訊，培養世界觀；把握每次簡報的機會；進修英文，也可以修第二外語 |
| 資訊管理 | 修資訊科技課程；把演算法和系統運作邏輯轉成逐行的程式；參加資訊社團或專題，把使用者需求轉成資訊系統 |
| 行銷經營 | 為社團成果發表或班級活動寫行銷企劃；研究品牌轉型的實際案例；經營自己的網誌或社群平台，一週寫一篇文章 |

系所在 ColleGo! 寫的建議也可以參考。成大企管建議閱讀企業經營、商業發展與財務金融的報導，練習整理論點、提出個人觀點並和他人討論，再嘗試問題式探究，用小論文呈現成果。中興企管建議修商業或管理相關的選修課程，撰寫商業或管理課程的學習成果。

下面是可以直接拿來改的題目例子，換成你學校、你身邊的對象就能做：

| 方向 | 題目例子 |
|---|---|
| 數據分析 | 設計線上問卷調查同學對學校午餐的滿意度，用試算表或 Python 整理、畫圖，再把改善建議交給膳食委員會 |
| 公開資料 | 用政府公開資料看一個消費或產業趨勢，例如某類商品近幾年的銷售變化，寫出你的觀察和推測的原因 |
| 社群行銷 | 幫社團經營社群帳號一學期，分析後台數據，找出哪類貼文互動高、哪個時段發文效果好，再調整做法 |
| 品牌與商業模式 | 用 SWOT 分析一個你常去的品牌，例如住家附近的連鎖飲料店，比較它和對手的做法 |
| 永續與社會企業 | 研究一家社會企業怎麼同時顧到營收和社會目標，能訪問到經營者更好 |
| 國際企業 | 追一則關稅或國際時事，整理它對某個台灣產業或供應鏈的影響；學第二外語的，可以研究那個國家的消費習慣 |
| AI 工具 | 用生成式 AI 幫忙發想行銷文案或整理資料，記下它哪裡好用、哪裡出錯，寫成你對 AI 能力和限制的觀察 |

## 把專題寫出深度

專題報告可以照個案分析的順序寫：

1. 情境：題目的背景是什麼，你為什麼選它。
2. 挑戰：過程中遇到什麼困難，例如資料不夠、問卷回收太少。
3. 行動：你怎麼解決。
4. 結果與反思：結果如何，不管成功或失敗，你學到什麼，想法有什麼改變。

寫反思時，用三層提問一層一層往下問：

1. 我做了什麼？例如：我用問卷和試算表分析了同學對午餐的滿意度。
2. 我從中學到什麼？例如：我學會整理和視覺化資料，也發現同一份數據可以有不同解讀。
3. 這和我想讀的系有什麼關係？例如：這讓我想多學商業分析，而這個系大二開的商業分析課正好在教這些。

第三層要寫到目標校系的具體課程或老師，這部分要先去看系網的課程地圖和師資介紹。

## 執行時要注意

- 目標訂小一點、清楚一點。簡單的題目，只要有訂目標、排進度、執行、交出成果的完整過程就有價值。
- 留下過程紀錄，例如每階段的筆記、改過的版本、為什麼改。
- 要附反思心得。只上傳學習單或簡報、沒有心得，是常見的缺失。
- 用 AI 協助準備資料的規定，見〈申請備審與面試要點〉。
