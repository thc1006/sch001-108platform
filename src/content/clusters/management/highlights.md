高中生準備多元表現最常犯的錯,是「流水帳式羅列經歷」。成功的關鍵在於「**詮釋**」——把每一項經歷策略性地建構成「證明管理潛力」的有力證據。這一頁告訴你:哪些經驗有價值、怎麼呈現、以及絕對要避開的地雷。

## 一、核心心法:重質不重量,頭銜不等於實力

教授審查時間極為有限,他們追求的是「效率」與「關聯性」,看重的是「**質**」而非「**量**」。

- 一份塞滿「一日遊」式志工、短期營隊、無關才藝檢定的厚履歷,反而是「缺乏焦點」「沒有深度」的證據。
- 一份能深入探討某個社會或商業議題的探究報告,或一段展現長期投入與成長的社團經驗,價值遠勝十份零散證書。

**頭銜本身幾乎沒有意義。** 各校審查指引一致要求的是頭銜背後的「具體貢獻」:

- 中興大學企管系:「說明擔任幹部職務,具有何種管理相關能力,並附有**具體事證**」
- 台灣大學工管系:要求分享社團活動的「**具體收獲與反思**」
- 成功大學會計系:「說明你在團隊中扮演什麼角色、為團隊做出什麼貢獻、如何處理衝突」
- 東吳大學企管系:「說明參與動機、投入程度、成效,並展現個人收穫與心得反思」

> 一個無法說明自己具體作為的社長,其領導力證明甚至不如一個能清晰闡述自己如何在團隊中扮演關鍵協調角色的普通組員。

## 二、用 STAR 原則把經驗變成證據

STAR 是業界與學術界呈現成就的標準框架。任何一項經驗——社團幹部、專題組長、活動總召——都應依此梳理:

| 要素 | 內容 | 範例 |
| :--- | :--- | :--- |
| **S 情境** | 簡潔設定背景與挑戰 | 「社團年度義賣活動,學生參與度逐年下滑」 |
| **T 任務** | 你被賦予的具體責任 | 「身為行銷組長,我的目標是一個月內把關注度提升 50%」 |
| **A 行動** | 你採取的具體步驟(多用「我」當主語) | 「我設計問卷了解興趣、帶領五人發起社群媒體互動投票、洽談手搖飲店合作」 |
| **R 結果** | 量化的成果 + 學到什麼 | 「來客數較前年提升 80%,募款超出目標 25%,觸及超過 3,000 人」 |

**進階版 STAR-F(Failure):** 對失敗的反思更能展現成熟度——「最初的宣傳計畫失敗了,我從中學到…,因此迅速調整策略,轉而…,最終才成功。」

## 三、各類亮點怎麼呈現

### 社團經驗
社團是高中生最早接觸的「管理實踐場域」。教授感興趣的不是社團名稱或頭銜,而是其中進行的「管理實驗」(採取的行動、解決的問題、達成的貢獻)。
- **盡可能量化:** 不要說「管理預算」,要說「管理一筆 50,000 元的活動預算」;不要說「增加社員」,要說「一學期內社員從 40 人增至 60 人,成長 50%」。
- **聚焦改變前後:** 行動前問題是什麼?行動後改善了多少?

### 競賽
商業競賽從市場分析、策略發想、財務估算到簡報,整個過程就是規劃、執行與創新的實戰演練,也是展現團隊合作的絕佳舞台。**但沒參加過商業競賽或模擬聯合國,並不代表沒競爭力**——一次成功的班級園遊會、自發組織的讀書會、有系統的網路銷售,只要妥善詮釋,都是展現管理能力的好案例。

### 活動與專案
任何「專案」經驗(籌辦班級活動、完成小論文、規劃家庭旅行)都可視為一個管理專案來解構,找出對應領導力、解決問題、規劃執行的具體事證。

### 網路經營與作品
經營個人 IG 品牌、社群帳號等經驗,可拆解成市場分析、品牌定位、顧客關係管理、數位行銷等多面向的管理能力證明。一個有創意的呈現方式(如用漫畫形式呈現反思),若與科系特質緊密結合,也能獲教授高度評價。

## 四、ESG 框架:把零散活動整合成價值主張

ESG 是全球企業界衡量永續發展的關鍵指標,可用來策略性地梳理你的經歷:

- **E(環境):** 環保社團、綠色能源自主學習、永續材料科展。
- **S(社會):** 長期志工服務、社會企業參訪、團隊合作中的溝通與同理。
- **G(治理):** 擔任社團幹部時建立制度、處理衝突、確保團隊運作,是公司治理能力的雛形。

透過 ESG 框架,你能把看似零散的活動整合成連貫、具現代商業思維高度的價值主張。

## 五、避雷指南:多元表現 10 大地雷

| 地雷 | 為什麼是地雷 |
| :--- | :--- |
| **流水帳式羅列** | 只記事件不反思,缺乏「學到什麼」 |
| **只列頭銜不談貢獻** | 教授要看實績,不是名片 |
| **「一日遊」式志工/單場演講** | 難以展現長期投入與深刻學習 |
| **以量取勝、履歷越厚越好** | 違反「重質不重量」,反顯缺乏焦點 |
| **摘要草率、標題乏味** | 100 字簡述決定教授是否點開細看 |
| **排版混亂、視覺災難** | 過多顏色與粗體模糊重點,反映缺乏組織能力 |
| **滿篇錯別字** | 寫錯校系名稱直接反映草率,絕不可犯 |
| **套用網路模板的八股文** | 沒有個人特色,缺乏鑑別度 |
| **誇大或杜撰經歷** | 申請過程的「自殺行為」,面試追問必被識破 |
| **只上傳學習單/簡報卻無反思** | 缺少賦予經歷價值的核心環節 |
