## 審查原則

教育部大學多元入學升學網的常見問題寫，招聯會彙整的「大學針對申請入學備審資料審查參考原則」有「三重二不」：「重視基本素養所展現的核心能力」、「重視校內的學習活動」、「重視資料眞實性及學生自主準備」、「不是學系所列的所有項次都要具備，大學重視多面向的參採」、「不是以量取勝，重視學習過程的反思」。

## 營隊

同一份常見問題回答參加大學營隊有沒有幫助：「參加營隊只能視為興趣探索及瞭解學群學系特色的方式之一」。教育部已函示各大學，營隊如涉及學習歷程檔案的準備或充實，不得收費，也不可授予參與證明。

風傳媒 2024 年報導，時任教育部次長葉丙成在臉書寫，申請大學時教授不會因為看到有參加營隊就加分，請家長「不要以為有參加營隊的紀錄推甄會加分而參加營隊」；如果是想多了解科系而參加，他不反對。

## GitHub 與作品

ColleGo! 資訊工程學類頁建議建立自己的 GitHub 帳號，把專案放上公開平台，訓練程式撰寫和表達能力；公開原始碼也可能和網友互動，提升溝通和技術能力。成大資工智慧系統實作組要求附 GitHub 連結，政大資管建議把作品長期放在 GitHub 或 HackMD，詳見〈申請備審與面試要點〉。

APCS 是程式能力的檢定，申請入學 APCS 組的級分規定詳見〈科系風向標〉。

## 開源貢獻

財團法人開源基金會的「AI 開源新勢力行動方案」（TAIONE Fellowship Program）不用提案也不是競賽，沒有開源經驗也能參加。有興趣的人填官網上的報名表，加入 vLLM、Kubernetes 等 11 個開源專案裡自己選的社群；常見問題頁寫，不用等基金會確認報名資料就能先加入討論，從文件、測試、小型 Bug 或 Good First Issue 開始。

Fellow 由各專案的技術嚮導（Track Lead）依實際貢獻提名，學生優先，通過基金會審核後簽約。Fellow 要具中華民國國籍、30 歲以下（含）、具備基礎程式能力（不限語言）。不符資格的人仍可用社群共學員的身分參與。未滿 18 歲能否成為 Fellow，官方資料沒有寫。

Fellow 從通過審核的次月起每月領 20,000 元，按季發放；當月完成功能優化、API 擴充，或挑戰 Hard Bug 這類貢獻並通過審查，有機會再加 10,000 元（卓越貢獻獎勵）。每月要做約 10 分鐘的技術分享；每三個月為一期，期滿前由技術嚮導評估是否續任，同一個專案最多兩年。

## 學生計算機年會

學生計算機年會（SITCON）由學生自發舉辦，不向與會者收費，官網寫已辦過 13 屆年會。SITCON 2027 在 2027 年 3 月 13 日於中央研究院人文社會科學館舉行，開放一般議程、開放式議程和 Demo 展（現場展示作品）投稿，早鳥投稿到 2026 年 11 月 29 日截止。
