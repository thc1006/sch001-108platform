## 學群看重的能力

ColleGo! 資訊學群頁列的多元能力是數理科學、程式設計、邏輯推理、主動學習、問題解決、語文理解與表達、系統運作，性格特質是主動積極、堅毅負責、合作互助。

## 各學類看重的科目與能力

下表是 ColleGo! 各學類頁列的前三名。本表只列 8 個學類，不列電機工程、光電工程、電子工程、通訊工程、電機資訊。

| 學類 | 高中科目 | 多元能力 |
| :---- | :---- | :---- |
| 資訊工程 | 數學、資訊科技、英語文 | 程式設計、數理科學、邏輯推理 |
| 資訊管理 | 資訊科技、英語文、數學 | 程式設計、邏輯推理、問題解決 |
| 數據統計 | 數學、資訊科技、英語文 | 數理科學、程式設計、邏輯推理 |
| 生物資訊 | 數學、資訊科技；英語文與生物並列第三 | 程式設計；問題解決與數理科學並列第二 |
| 資訊傳播 | 國語文與資訊科技並列第一；英語文與藝術生活並列第三 | 語文理解與表達、主動學習、邏輯推理 |
| 媒體設計 | 美術、藝術生活、資訊科技 | 主動學習、敏銳創造、問題解決 |
| 圖書資訊 | 英語文、資訊科技、國語文 | 語文理解與表達、快速知覺與總結；批判思考與主動學習並列第三 |
| 數位學習 | 資訊科技；國語文與數學並列第二 | 問題解決、敏銳創造、主動學習 |

資訊工程學類頁也寫，適合的人熱愛觀察事情的細微運作，想用程式語言讓事情運作得更完善，有溝通能力與變通性，能把遇到的問題簡化或細緻化來解決。

## 系上怎麼說

清大資工系在 ColleGo! 列了三種學習方法：課程範圍大，上課很難講完，要靠自我加強和預習；領域廣，遇到不熟悉的部分要自己學習與摸索；課堂常要和他人一起做專案，要能和隊友溝通討論。

CASE 報科學 2023 年刊出謝達文採訪清大資工陳宜欣教授的專訪。陳宜欣說，她的實驗室找研究題目，經常是她先拋出幾個大方向，有學生有興趣，大家再一起討論題目是否有趣、是否可行，值不值得投資時間；她用自己的話稱這是「探尋」的邏輯。
