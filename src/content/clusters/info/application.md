# 資訊學群申請備審與面試要點

備審資料不是過往成就的彙整,而是一份策略性的敘事。這一頁整合學習歷程的結構、自述寫法、面試準備與時程規劃,幫你把高中三年的軌跡,轉化為一個讓教授「輕而易舉」做出錄取決定的故事。

## 備審資料結構

第二階段審查資料通常包含:修課紀錄、課程學習成果(至多勾選 3 件)、多元表現(至多勾選 10 件)、學習歷程自述、就讀動機與學習計畫。這些項目並非彼此孤立,而應由一條「黃金主線」串連——一個驅動你高中三年探索的核心提問或主題(例如「如何透過數據視覺化讓複雜資訊變得平易近人?」)。

- **修課紀錄** — 不只是成績單。主動在自述中詮釋你的選課邏輯;若某科成績不理想,誠實面對並說明你如何調整學習方法,這種成熟反思遠勝過一個無法解釋的低分。
- **課程學習成果** — 切勿「單純貼上資料後繳交」,必須加上心得與簡要解釋。建議為每份成果附一頁摘要,用「問題 → 策略 → 行動 → 反思」框架闡述核心價值。
- **多元表現** — 重質不重量,展現超越課堂的「深度、動機與啟發」。

## 課程成果與多元表現的反思框架

每一份上傳的成果,都建議用「動機—主題—收穫—反思」框架撰寫百字簡介或心得:

- **動機** — 「我做這件事,是因為……」把活動與課堂學習、個人興趣或觀察到的問題連結起來。
- **主題/過程** — 「在這項活動中,我主要做了……」簡潔描述核心內容與執行步驟。
- **收穫** — 「透過這個過程,我學會了/得到了……」具體說明硬技能與軟技能。
- **反思/未來** — 「這次經驗讓我確認了……,並計劃未來……」將單次經驗連結到長遠的學術與生涯規劃。

對於團隊專案,務必明確劃出「我的具體貢獻」區塊,用「獨立負責」「核心功能開發」等具體動詞,連結到具體技術,精確回答教授心中「你到底做了什麼」的疑問。

## 學習歷程自述:敘事的靈魂

調查顯示高達 45% 的教授會優先點開「學習歷程自述」——這是教授認識你的第一印象。一份空洞、套模板、甚至錯字連篇的自述,會讓後續精彩成果都大打折扣。建議採用四段式敘事結構:

1. **動機/引子** — 以一個具體的個人故事或引發興趣的特定問題開頭。避免「我從小就對電腦充滿熱情」這類陳腔濫調。
2. **行動/證據** — 簡潔描述你為追尋熱情投入的關鍵專案與學習,並巧妙引導教授查閱你的證據(如 GitHub 連結)。
3. **學習/洞見** — 最關鍵的部分。你從成功、更重要的是從失敗中學到了什麼?展現你的反思能力與心智成熟度。
4. **未來/契合度** — 把過去的旅程與未來抱負連結,論證為何「這個特定科系」是你合乎邏輯的下一步。具體提及該系的課程、教授研究方向或資源,證明你做過深入研究。

可以把自述構建成「火花—旅程—未來」三幕劇:起源故事、高中探索之路、對該校系的願景。針對不同校系應微調敘事——成大資工要直接回應「最大困難與挑戰」的提問;清大資工要突顯自學與探索;陽明交大資工要呈現競賽與外語實力;政大資管要帶入商業與使用者視角;台大資工要展現對特定次領域(如生成式 AI、AI Agent、資安、演算法理論)的深度理解。

## 誠信:不可逾越的紅線

2025 年一起學習歷程造假事件成為分水嶺:一名學測 74 級分的學生因將辯論比賽「單場優秀辯士」誇大為「最佳辯士」、推薦函「沒有補習」陳述與本人社群貼文矛盾,遭陽明交大、北醫大、中山醫大等多校醫學系撤銷錄取資格;教育部更於統一分發前發函取消其分發資格。台大校長陳文章強調學習歷程的核心是「忠實呈現你自己」,任何獎項或成果都應附上佐證資料。

這起事件把申請重心從「說服」轉變為「驗證」——檔案中每一項陳述都必須可查核。也因此,**誠實描述挑戰、失敗與從中學到的教訓,反而是最安全也最有說服力的策略。** 在 AI 能流暢代寫的 2026 年,這條紅線延伸至「用 AI 代寫且無法說明」的情境。

## 面試準備

備審寫得再厲害,面試時若對細節閃爍其詞,反而暴露其虛假。準備方式:

- **為每個專案準備三層論述** — 一句話總結、三分鐘介紹(背景、動機、技術貢獻、成果)、十分鐘概述(技術細節、挑戰與解決)。提前把細節寫下來。
- **用 STAR-TP 框架敘述問題解決** — 情境、任務、行動、結果,加上最關鍵的「思維過程」(解釋行動背後的「為什麼」)。
- **準備好談「弱點」** — 成績不佳、競賽失利不必迴避,把它框架成塑造韌性與學習態度的契機。
- **想清楚你的「附加價值」** — 你能為這個系上社群帶來什麼?例如指導學弟妹程式設計、參與系上推廣營隊,把自己從「教育消費者」轉變為「生態貢獻者」。

## 三學年備審時程

- **高一(探索與奠基)** — 專注數學、英文等核心學科;善用校內資訊課與社團廣泛探索;養成記錄學習心得的習慣。
- **高二(深化與實驗)** — 聚焦一至兩個領域;善用自主學習時間執行個人專案;建立 GitHub 帳號並練習撰寫 README。
- **高三(統合與敘事)** — 精煉核心專案,加強文件與反思;投入大量時間撰寫學習歷程自述與綜整心得;完成初稿後務必尋求老師校閱。

## 最終提交前自我審核清單

- 真實性:每一項內容是否 100% 真實、可查證?引用的獎項是否都有證明文件?
- 敘事性:自述是否講述一個清晰、連貫的故事?挑選的成果是否都支持這個核心故事?
- 品質:每份成果是否附上有深度的反思,而非檔案堆砌?
- 相關性:每一項內容如何具體展現你對目標科系的興趣與潛力?
- 清晰度:文字是否清晰、簡潔、沒有錯別字?是否已請至少一位老師協助校閱?
