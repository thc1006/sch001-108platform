關於財經科系（經濟、財務金融、會計、財稅、保險、國際企業）的選填與申請，網路上流傳著許多似是而非的說法。這份指南針對申請者常見的迷思與錯誤逐一澄清，從科系本質、數學門檻到備審準備，並附上快速檢核總表。

## 一、關於「科系本質」的迷思

### 迷思一：財金、財管、財政、會計都差不多，反正都是商學院

**真相：不一樣。**

- **財務金融**：研究金融市場運作與企業財務決策，重市場、投資、風險、報酬。
- **財務管理**：偏企業內部的財務決策與管理（政大將其與金融系分開設系）。
- **財政**：研究政府部門的財政與公共財（政大財政系隸屬社會科學學院）。
- **會計**：記錄、分析、溝通企業財務資訊，重財報、稅務、內控、審計。
- **經濟**：探究資源最適分配的社會科學，偏理論與模型。

特別注意一個結構性事實：**政大沒有「財金系」**，而是拆成金融、財務管理、風險管理與保險三系；台大則把商管集中於管理學院（財金系），經濟系另屬社會科學院。**選填志願前務必看清楚每個系的課程地圖**，不要被系名相似誤導。

### 迷思二：數學不好就不能念財金 / 經濟

**真相：需要校正。「迴避量化」是地雷，但「高中數學不頂尖」不等於「不能念」。**

一方面，ColleGo! 的會計學類介紹寫：「會計學的數學運算，幾乎只會用到加減乘除。」ColleGo! 的財金學類，第一名能力是「語文理解與表達」而非數學。

但另一方面，務必認清：**經濟系與計量財務金融系確實高度倚賴數學**。ColleGo! 顯示經濟學類核心能力前兩名是邏輯推理與數理科學；清大計財系必修高等微積分、線性代數；微積分與統計是所有商學系的必修。

**正確結論**：你不需要是數學競賽選手才能念財經，但你必須願意與微積分、統計為伴，並具備穩定的邏輯與數理基礎。真正的地雷是「因為討厭數學而選財經，以為可以逃避」。若你極度排斥數學，經濟與計財系應審慎考慮，會計系相對是數理負擔較輕的選項。

### 迷思三：念財經 = 以後一定進銀行 / 一定賺大錢

**真相：財經出路廣，但「廣」不等於「自動高薪」，職涯需要主動規劃。**

ColleGo! 列出財務金融學類的生涯路徑包含金融交易員、財務分析、銀行辦事員、保險經紀、理財專員、財會主管、金融研究員等，薪資範圍跨度大。關鍵事實：

- 金融業範疇很大，除業務職外，還有中後台、交易室、分析師、研究員等不同性質的工作，薪資與發展差異大。
- 財經學群也是公職的熱門背景（會計、財稅尤其對應公職考科）。

**正確結論**：財經出路確實廣，但「廣」意味著你需要在大學期間主動探索、選定方向、累積能力，而非被動等待。

## 二、關於「申請準備」的迷思

### 迷思四：備審資料活動越多、獎狀越多越好

**真相：份數多不代表好。** 台大財金系陳彥行教授在 Yory 優歷的專訪說：「你傳三份 70 分的，或傳五份 60 分，你不如傳一份 90 分的給我看。」談到投資競賽，他說得獎有時是運氣，「重要是那個過程中你到底學了什麼東西？」

### 迷思五：一份備審資料可以投好幾個財經科系，反正都是財經

**真相：台大財金系陳明賢教授在 IOH 的專訪裡特別提醒過這件事。** 專訪寫，最可惜的是把同一份學習歷程資料拿去申請不同科系，內容沒有為科系量身打造。專訪引述他的話：「如果你的學習歷程資料像瑞士刀一樣什麼都可以用的話，那非常有可能每個教授都會覺得你沒有寫到他想要看到的東西。」幾個財金系的教授與招生文件各寫了這些：台大財金系陳彥行教授把數學（特別是統計學）與英文列為讀完財金系的基本學業素養；中正財金的招生目標寫「具備自主學習，重視團隊合作，且樂於培養國際化視野與創新能力之學生」，審查看的能力也包括外語能力；中興財金的準備指引說修課紀錄看學期成績平均與單科分數，「較為重視英文、數學領域」；中原財金在校系分則寫「面對嶄新金融科技(Fintech)的時代」，教學要落實資訊化、國際化與實務性。**備審必須針對申請的校系客製化**，學習動機與讀書計畫尤其要聚焦該系。

### 迷思六：自主學習隨便做做就好，反正不重要

**真相：ColleGo! 2023 年的財經學群小福袋寫，「幾乎所有學系都強調高中自主學習計畫與成果的必要性」。** 列不列、佔多少份量因校系而異，以目標校系當年度的審查資料準備指引為準。

### 迷思七：備審資料只能寫成功、不能寫失敗

**真相：失敗的經驗也可以寫，重點是反思。** 例如照「模擬投資虧損→檢討決策→修正策略」記錄。寫失敗要落在「我學到什麼、怎麼修正」，不要只是抱怨或自我貶低。

### 迷思八：面試一定要展現很強的財經專業知識，答不出來就完蛋

**真相：專業知識不足不一定扣分。** IOH 的專訪寫，台大財金系陳明賢教授認為，比起展現專業能力，面試更重要的是建立好印象，因為高中生往往難以把專業知識詮釋得當；面試時要專注傾聽、和教授眼神接觸，讓教授感受到你的真誠。準備重心放在說清楚自己的經歷，不必死背財經名詞。

## 三、關於「能力認知」的常見錯誤

- **錯誤一：以為財經人「只要會算數、不用文筆」**：ColleGo! 顯示「語文理解與表達」是財務金融學類的第一名核心能力。財經工作大量涉及研究報告撰寫、提案、客戶溝通。
- **錯誤二：以為「資訊 / 程式」與財經無關**：ColleGo! 的財務金融學類介紹寫，運用大數據資料分析、解決各種金融問題「更是未來趨勢」；ColleGo! 的核心課程地圖列出，清大計量財務金融學系大一必修資訊工程導論、計算機程式設計。
- **錯誤三：以為「經濟系 = 教你怎麼投資賺錢」**：經濟系偏理論，學的是個體/總體經濟模型、計量經濟學，用來理解「整體經濟體系如何運作」，不是教你選股。想學投資操作，財金系更貼近。

| 迷思 | 真相 |
|---|---|
| 財金財管財政會計都一樣 | 本質不同，政大甚至無「財金系」，選系前必看課程地圖 |
| 數學不好不能念財經 | 高中數學非頂尖仍可念，但「想逃避數學」是地雷；經濟、計財確實重數理 |
| 念財經自動高薪 | 出路廣但需主動規劃，金融業內職務性質差異大 |
| 備審越多越好 | 台大財金系陳彥行教授：「你不如傳一份 90 分的給我看」 |
| 一份備審投多系 | 台大財金系陳明賢教授提醒，一份資料投多系，每個系的教授都不會覺得是為它而寫，必須客製化 |
| 自主學習不重要 | 幾乎所有財經學系都強調 |
| 備審只能寫成功 | 誠實寫失敗＋反思更有價值 |
| 面試要很強的專業知識 | 專業知識不足不一定扣分，建立好印象更重要 |
| 財經人只要會算數 | 語文表達是財金第一名能力 |
| 資訊程式與財經無關 | ColleGo! 把大數據資料分析寫成未來趨勢，清大計財系大一必修計算機程式設計 |
| 經濟系教你投資賺錢 | 經濟偏理論模型，想學投資操作選財金 |
