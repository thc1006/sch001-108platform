下面兩張表是 ColleGo! 列的各學類前幾名的特質與能力，排越前面，代表學類裡的校系越重視。

## 性格特質

ColleGo! 在財經學群列的性格特質是主動積極、堅毅負責、合作互助。三個學類的前三名：

| 學類 | 第一 | 第二 | 第三 |
|---|---|---|---|
| 財務金融 | 主動積極 | 堅毅負責 | 樂群敬業 |
| 經濟 | 主動積極 | 深思力行 | 變通開創 |
| 會計 | 堅毅負責 | 合作互助 | 深思力行 |

## 多元能力

學群層級列的是語文理解與表達、邏輯推理、主動學習、問題解決、數理科學、批判思考。三個學類的前四名：

| 學類 | 第一 | 第二 | 第三 | 第四 |
|---|---|---|---|---|
| 財務金融 | 語文理解與表達 | 邏輯推理 | 主動學習 | 數理科學 |
| 經濟 | 邏輯推理 | 數理科學 | 問題解決 | 主動學習 |
| 會計 | 邏輯推理 | 語文理解與表達 | 主動學習 | 問題解決 |

財金的第一名是語文理解與表達。寫報告、做簡報、和客戶溝通，都靠這項能力，念財經不是只會算數就好。

## 台大財金系兩位教授的看法

陳明賢教授說，他看學習歷程資料注重三個面向。知識背景是高中學科的底子，加上對該系課程的了解。技能方面，金融業是服務業，強調領導力與團隊合作，最好用社團經驗證明。態度方面，財金工作可能要管理大量的金錢，道德操守和小心謹慎很重要。他也建議在資料裡寫出讀過《經濟學人》或《紐約時報》的哪一篇文章、文章說未來的趨勢往哪裡走。那篇訪問也問了一個問題：對財金系有興趣的話，你知道什麼是金融科技嗎？

陳彥行教授列了四項：數學和英文是讀完財金系的基本學業素養，其中統計學「格外重要」；交易建立在信任上，要有良好的品德操守；金融業高度管制，要細心、重視細節；金融業是與人打交道的工作，業務性的工作看重儀表、談吐與人際技巧。他也提醒，進財金職場前先想想自己的個性和體力能不能適應「高薪高壓高工時」的環境。

## 在備審裡怎麼佐證

| 能力或特質 | 可以拿來佐證的東西 |
|---|---|
| 數學、統計、邏輯推理 | 數學科成績、數理課程的學習成果、相關比賽 |
| 英文 | 英文檢定、英文科成績、英文閱讀或寫作的課程成果 |
| 資訊與程式 | 程式設計課程、用 Python 或 Excel 做的自主學習或數據分析作品 |
| 財經知識 | 商業概論、會計學原理等選修課，財經閱讀筆記，探究報告 |
| 語文理解與表達 | 報告、簡報、文章、訪談紀錄 |
| 主動學習 | 自主學習計畫與成果 |
| 批判思考 | 對一個財經議題整理正反意見，寫出你的判斷 |
| 領導與團隊合作 | 社團幹部、比賽團隊裡你負責的部分 |
| 細心與嚴謹 | 帳務整理、資料整理的精確程度，例如社團收支表 |

## 把特質寫成經歷

「我很有邏輯」「我對數字很敏感」這類句子只是宣稱，讀的人無從判斷。寫一件做過的事，照四步寫：

1. 情境：當時面對什麼任務或問題。
2. 困難：卡在哪裡，有什麼衝突。
3. 行動：你具體做了什麼。能力要在這裡看出來。
4. 結果與反思：結果怎樣，學到什麼，這件事怎麼改變你的想法或做法。

下表是示範寫法，右欄把同一個特質寫成做過什麼、發現什麼、怎麼改變了你：

| 只有宣稱 | 寫出經歷 |
|---|---|
| 我對數字很敏感。 | 我用 Excel 整理班費三學期的收支，發現有一筆支出每月固定偏高，追查後是一項沒取消的訂閱。這讓我發現記帳不是記完就好，要定期回頭看。 |
| 我很有領導力。 | 投資模擬競賽時組員對選股意見分歧，我提議各自用一週的資料回測再比較，最後整合出一個組合。我學到意見不合時，可以先把爭論變成能驗證的問題。 |
| 我對經濟議題有興趣。 | 我追蹤央行升息的新聞，試著用課堂學的供需模型解釋它對房貸族的影響，也發現模型太簡化。這讓我想多學一點總體經濟，看懂更完整的解釋。 |
