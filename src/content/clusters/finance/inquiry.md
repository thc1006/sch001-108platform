ColleGo! 的財經學群小福袋說，財經學系有的看重溝通表達、領導合作，有的偏重競賽、檢定證照，但「幾乎所有學系都強調高中自主學習計畫與成果的必要性」。各系有沒有採計，以當年度的審查資料準備指引為準。面試時教授也常從這份成果問起，做過的事要講得出來。

## 怎麼選題

台大財金系陳彥行教授建議從生活裡找企劃，例如比較不同銀行的開戶體驗；也可以看完一系列財金相關的 YouTube 影片，挑一個企劃自己做實驗複製，驗證它可不可信。他說，自主學習「最好是你這裡面帶了一個實驗，或是帶了一個你要實際上去操作、去設計的事情」，做出成果並附上數據，比看完一本書具體。

挑題目時可以用三件事檢查：

- 和財經有連結：說得出這個題目和你想讀的經濟、財金或會計有什麼關係。
- 可以操作、可以驗證：有調查、有數據、有實作，不只是讀。
- 有你自己的角度：從你的生活和好奇出發，不要直接拿網路上的通用題目。

自己感興趣的事和想讀的科系重疊的地方，通常就是好題目。

## 計畫和成果怎麼寫

自主學習計畫沒有規定格式，寫清楚學習主題、目標、內容、時數和方法就可以。成果報告可以照五段整理：

1. 動機：為什麼想研究這個，和你的經驗或財經興趣有什麼關係。
2. 問題：想回答的具體問題是什麼，越聚焦越好。
3. 方法：打算怎麼做，例如閱讀、訪談、問卷、整理數據、模擬。
4. 執行與產出：實際做了什麼、做出什麼。
5. 反思：遇到什麼困難，哪裡和預期不同，學到什麼，對選系有什麼影響。

執行時失敗也能寫進成果，說清楚問題出在哪、怎麼改進。

## 題目例子

下面的例子用來找靈感，不要照抄。好題目通常來自你自己的生活。

| 學類 | 題目例子 |
|---|---|
| 經濟 | 校園周邊飲料店的定價：用供需與成本解釋價差；演唱會黃牛票與價格管制；最低工資調整的正反論點整理；用主計總處、央行的公開資料看物價、失業率的變化；同學在先付款和後付款兩種情境下的消費選擇（小型問卷實驗） |
| 財務金融 | 模擬投資組合，記錄每次決策的依據、結果與檢討，虧損和判斷錯誤也照實寫；ETF 與個股的風險報酬比較；定期定額與單筆投入的長期模擬；同學的金融素養問卷 |
| 會計 | 社團或班費從流水帳整理成簡易財務報表；選一家熟悉的上市公司，讀它的損益表和資產負債表，寫下理解與疑問 |
| 國際企業 | 一個跨國品牌在台灣的在地化做法；匯率變動對留學費用的影響 |
| 財稅 | 從一個縣市的總預算看政府的錢花在哪裡；一張發票背後的營業稅 |
| 保險 | 從風險分散理解保險；高中生需要哪些基本保障 |
| 跨域 | 綠色基金與一般基金的比較；用 Python 把某一類股票的歷史價格畫成圖 |

## 常見錯誤

1. 題目太大，做不完：「研究全球經濟」高中生做不完。「我家附近三家超商的鮮食定價」比「探討零售業定價」做得完，也做得深。
2. 只有閱讀，沒有產出：讀完一本書只寫摘要，看不出你做了什麼。要有自己的調查、數據、實作或觀點。
3. 和財經科系沒有連結：題目和財經無關，也寫不出關係，這份成果就幫不上你申請財經系。
4. 沒有反思，或反思只寫「收穫滿滿」這類空話：要寫出哪裡和預期不同、你怎麼修正、這件事怎麼影響你選系。
5. 計畫和成果對不上：計畫書寫 A，成果做成 B，卻沒說明為什麼改。中途調整方向可以，把轉折和原因交代清楚。
