心理師曲慧娟等人在 ColleGo! 寫的〈【112申請入學】財經學群小福袋〉說，財經學系有的看重溝通表達、領導合作，有的偏重競賽、檢定證照，但「幾乎所有學系都強調高中自主學習計畫與成果的必要性」。各系有沒有採計，以當年度的審查資料準備指引為準。

## 怎麼選題

台大財金系陳彥行教授在 Yory 優歷的專訪建議從生活裡找企劃，例如比較不同銀行的開戶體驗。也可以看完一系列財金相關的 YouTube 影片，挑一個企劃自己做實驗複製，驗證它可不可信。他說，自主學習「最好是你這裡面帶了一個實驗，或是帶了一個你要實際上去操作、去設計的事情」，做出成果並附上數據，比看完一本書具體。和想讀的科系有連結會更好。

親子天下的整理寫，自主學習計畫沒有規定格式，架構寫清楚學習主題、目標、內容、時數和方法就可以。執行時失敗也能寫進成果，說清楚問題出在哪、怎麼改進。

## 題目例子

下表是本站列的方向，用來找靈感：

| 學類 | 題目例子 |
|---|---|
| 經濟 | 校園周邊飲料店的定價：用供需與成本解釋價差；演唱會黃牛票與價格管制；最低工資調整的正反論點整理 |
| 財務金融 | 模擬投資組合，記錄每次決策的依據、結果與檢討；ETF 與個股的風險報酬比較；定期定額與單筆投入的長期模擬；同學的金融素養問卷 |
| 會計 | 社團或班費從流水帳整理成簡易財務報表；選一家熟悉的上市公司，讀它的損益表和資產負債表，寫下理解與疑問 |
| 國際企業 | 一個跨國品牌在台灣的在地化做法；匯率變動對留學費用的影響 |
| 財稅 | 從一個縣市的總預算看政府的錢花在哪裡；一張發票背後的營業稅 |
| 保險 | 從風險分散理解保險；高中生需要哪些基本保障 |
| 跨域 | 綠色基金與一般基金的比較；用 Python 把某一類股票的歷史價格畫成圖 |

## 免費資源

- 台大開放式課程「基礎財金素養」：沿自台大財金系的「高中生線上財金素養教育」，共 15 講，內容有共同基金、期貨與選擇權、行為財務學、儲蓄規劃等。
- 清華雲：清大計財系在 ColleGo! 推薦財務決策分析、衍生性金融商品、計量財務經濟學、投資實務研討四門課。
- 教育部 108 課綱資訊網的自主學習專區，有自主學習成果、自主學習網站等分類。
