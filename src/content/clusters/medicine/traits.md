# 醫藥衛生學群教授看重的特質與能力

這一頁聚焦一個問題：**醫藥衛生學群的大學教授，在審查備審資料與進行面試時，究竟在尋找什麼樣的人？** 讀懂教授的思維，你才能精準準備。

## 一、核心命題：醫衛學群選的是「人」，不是「成績單」

要理解醫衛學群教授的思維，必須先接受一個前提：**這個學群培育的是直接對「人的生命與健康」負責的專業人員。** 一名能力不足的工程師可能造成財產損失；一名特質不適合的醫療人員，則可能造成不可逆的傷害。因此，醫衛學群的選才，本質上是一場「適性與品格的篩檢」。

北醫醫學系教授在公開訪談中說得直接：他想看到的是「學生的人格特質和軟實力」，而非成就的堆砌；現代的好醫師需要溝通能力與人文素養，「技術已不是唯一考量」。

根據 ColleGo! 選才育才輔助系統，醫藥衛生學群明列的核心能力與性格特質為：

- **多元能力：** 主動學習、語文理解與表達、問題解決、邏輯推理、社會覺察與合作、批判思考。
- **性格特質：** 主動積極、合作互助、樂群敬業。
- **適合的興趣類型：** 研究型、實用型、社會型。

這份官方清單，就是教授審查時心中的「對照表」。

## 二、教授最看重的六大特質

### 特質一：同理心 — 但要「具體」，不要「口號」

同理心是醫衛學群所有科系的共同核心特質。長庚大學醫學系的核心能力、各校護理／物治／職治／聽語系的選才條件，幾乎無一例外將「同理心」「關懷」列為首要。

但教授對「同理心」的判讀極為敏銳。**「我喜歡幫助別人」「我很有愛心」這類抽象宣言，在審查室裡近乎無效**——因為每一份備審資料都這樣寫。教授尋找的是「具體、可驗證、有反思」的同理心證據：

> ❌ 不是：「我去醫院當志工，學到要關懷病人。」
>
> ✅ 而是：「我在醫院志工服務時，注意到一位獨自候診的長者反覆看時鐘，我主動上前協助確認看診進度，並陪他聊了十分鐘。這讓我意識到，醫療現場的焦慮往往不只來自疾病本身，更來自『不確定感』與『孤獨』。」

第二種寫法有力，是因為它展示了「觀察 → 行動 → 洞察」的完整鏈條。這也是各校審查指引反覆強調的「反思」——教授評估的不是你做了什麼，而是你從中「看見」了什麼。

> **值得注意的醫學人文議題：** 有研究指出，醫學生在進入臨床訓練後，同理心反而可能因高壓與情緒耗竭而下降。這正是教授希望在入學前就篩選出「同理心根基深厚、且有自我覺察能力」學生的原因——他們要找的不是現在很善良的人，而是能在未來高壓環境中「守住」善良的人。

### 特質二：抗壓性與心理韌性

醫衛專業的養成過程漫長且高壓：醫學系七年（含實習）、密集的國考、臨床輪訓的責任壓力。物治、職治等專業也明確要求學生具備「足夠的耐心與強大的心理抗壓與調適力」。

教授如何觀察抗壓性？關鍵在於 **「失敗敘事」**。多位教授明確表示，他們希望看到學生「比較有缺點的部分」，以及學生對此「有沒有一些想法」；不要「隱惡揚善」。

這是重要的策略訊號：**誠實呈現一次挫折（段考失利、競賽落敗、社團衝突、專題失敗），並說明你如何面對、調整、再出發，遠比羅列一串完美戰績更有說服力。** 它證明你不是溫室裡的花朵，而是一個能在挫折中復原、持續成長的人。

### 特質三：利他動機與服務精神 — 但動機要「夠大」

醫衛學群高度重視「服務人群」的動機。但北醫醫學系教授指出一個極常見的地雷：許多學生說自己習醫動機是「親戚朋友生病了」，教授認為「這樣的動機太小、太狹隘了」。

為什麼「家人生病」這個動機會被認為「太小」？因為它只證明你對「特定的人」有感情，無法證明你對「不認識的、廣大的陌生人群」有持續服務的意願——而後者才是醫療職業的本質。教授希望看到一個「更大的動機」：你是否曾因某個社會議題、某次服務經驗、某本書，而對「群體的健康」「醫療的公平」「生命的意義」產生超越個人的關懷。

### 特質四：溝通與人際能力

醫療是團隊工作，也是與病人、家屬持續對話的工作。ColleGo! 將「語文理解與表達」「社會覺察與合作」列為學群核心能力。MMI 面試更直接設有「溝通技巧站」，模擬向病人或家屬說明診斷的情境。

教授尋找的溝通能力證據包括：擔任幹部時協調衝突的經驗、跨組別合作的專題、需要對外解釋的服務（如衛教、導覽、教學）、辯論或簡報經驗。重點同樣是「具體事蹟」而非頭銜。

### 特質五：學術潛力與科學素養

醫衛學群，特別是醫學、牙醫、藥學、醫檢等學類，本質上是「應用科學」。教授需要確認申請者具備持續學習艱深科學知識的潛力。

- 醫學系幾乎都重視語文、數學、自然三領域的均衡發展，「科技領域」也幾乎成為國立醫學系的共識。
- 醫檢學類特別重視「分析問題的能力、對成因的好奇、注重細節、嚴謹解決實驗問題」。
- 物治、職治因需大量閱讀外文文獻，外語能力被視為必備。

學術潛力的證據：在校相關科目成績、探究與實作課程的成果、自主學習專題、科學閱讀心得、競賽經驗。但要注意——競賽不是唯一路徑。

### 特質六：誠實與專業倫理

這是所有特質的底線。醫療專業以「不傷害」「行善」「尊重自主」「公正」為四大倫理原則。在備審資料中，**杜撰、誇大、抄襲是最不可原諒的致命傷**——招聯會明文要求審查資料須為「本人實際的學習歷程，真實呈現」。一旦在面試追問中被識破，無論其他條件多優秀，幾乎注定出局。誠實不僅是道德要求，更是醫療專業的入門資格。

## 三、教授的「審查室 OS」：五句內心獨白

想像一位醫學系教授在深夜審閱成堆備審資料，他的內心可能上演這些劇場。讀懂它們，你就能更精準地準備。

- **「又是『因為阿公生病』⋯⋯」** → 動機千篇一律、太狹隘。教授要的是經過深刻思考、夠大、且專屬於你的動機。
- **「這個學生很誠實，他寫了自己第一次當志工時的不知所措，還有後來怎麼調整。」** → 這就是「反思」與「韌性」。誠實面對不足，反而加分。
- **「他把醫院志工的觀察，連結到了醫療資源分配的問題。有想法。」** → 從微觀經驗連結宏觀議題，展現「社會覺察」與思考深度。
- **「整份資料排版亂、錯字多、像流水帳。」** → 扣分。混亂的呈現增加教授的認知負荷，也反映申請者缺乏組織能力。
- **「看得出來他真的研究過我們系，提到了我們系的特色課程和老師。」** → 展現「申請動機的真誠」與「校系契合度」，是錄取的臨門一腳。

## 四、把特質「翻譯」成備審證據：對照表

教授無法直接「看見」你的特質，只能從你提供的「證據」去推論。下表協助你檢查：你的每一項特質，是否都有具體證據支撐？

| 教授看重的特質 | 弱證據（近乎無效） | 強證據（有說服力） |
|---|---|---|
| 同理心 | 「我很有愛心、喜歡助人」 | 一次具體服務中的觀察、行動與洞察，並說明它如何改變你 |
| 抗壓性／韌性 | 「我抗壓性很強」 | 一次真實挫折的完整敘事：發生什麼、你怎麼面對、學到什麼 |
| 利他動機 | 「家人生病所以想當醫生」 | 由社會議題、服務經驗或閱讀觸發的、超越個人的關懷 |
| 溝通能力 | 「我擔任社長」 | 一次協調衝突／跨組合作／對外說明的具體事件與反思 |
| 學術潛力 | 「我自然科很好」 | 探究專題、自主學習成果、科學閱讀的具體產出與思考 |
| 誠實 | （無法用文字宣告） | 通篇真實、不誇大；在面試追問下答案前後一致 |

## 五、給申請者的行動建議

1. **拿 ColleGo! 的核心能力清單當「自我盤點表」。** 主動學習、語文表達、問題解決、邏輯推理、社會覺察、批判思考——逐項問自己：我有哪一件具體經歷可以證明？
2. **每一項特質，都要有「故事」。** 抽象形容詞無效。用「情境—行動—結果—反思」（SARR）結構，把特質轉化成可信的敘事。
3. **不要害怕寫失敗。** 醫衛教授明確歡迎「有缺點、有想法」的真實學生。一次誠實的挫折反思，勝過十項完美獎項。
4. **把動機「做大」。** 從「我家人生病」升級到「我關心什麼樣的人、什麼樣的健康議題、什麼樣的醫療理想」。
5. **針對科系客製化。** 研究你申請的每一個校系的特色課程、師資、辦學理念，並在動機中具體呼應。
