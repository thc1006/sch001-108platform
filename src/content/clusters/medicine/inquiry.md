## 計畫與成果怎麼寫

「高中自主學習計畫與成果」是多元表現的一個項目，醫衛校系採不採計，要查各校系當年度的分則與準備指引。臺大醫學系 115 學年度的準備指引就採計這一項，要考生「具體說明自主學習計畫之收穫與反思」。

親子天下〈自主學習計畫怎麼寫？各校自主學習範例、資源一次看〉寫，自主學習計畫沒有規定的格式，架構寫清楚學習主題、目標、內容、時數和方法就可以。文中也引國立大學教師的說法：大學端並不期待高中生交出多艱深、多學術性的自主學習報告，能呈現對問題的敏感度、洞察力和解決問題的能力，就是教授最有興趣的。

成果不完美也可以寫。親子天下的王韻齡 2022 年的整理（刊在天下雜誌網站）引述台大園藝暨景觀學系教授林書妍：「做實驗沒有絕對成功的，失敗為成功之母，不要覺得失敗過程不能被記錄。」談到大學看重歷程還是成果，台北大學社會系教授陳婉琪在臉書上寫，「適度交代歷程的成果」應是理想的呈現。文中接著寫，作品普通，但交代了方法、看出現階段的缺失、說明下次怎麼改，就是完整的自主學習歷程。

國教署 108 課綱資訊網的自主學習專區，收錄了各校的自主學習成果範例。

## ColleGo! 建議的學類體驗

ColleGo! 每個學類頁的「學類體驗」，列了高中生可以做的活動：

| 學類 | ColleGo! 建議的體驗 |
|---|---|
| 醫學 | 訪問醫學生或醫師，了解各階段在做什麼、碰到什麼問題，評估自己適不適合 |
| 公共衛生 | 觀察一個疾病傳播的新聞事件，看預防措施是否有效，記錄疾病的變化和預防方式 |
| 牙醫 | 以特定模型為範本練習雕刻；學習和年長病患溝通 |
| 物理治療 | 加入運動團隊，了解骨骼肌肉的作動和運動傷害；從陪病、就診或醫療志工觀摩醫病互動，記下和原先想法的差異 |
| 職能治療 | 觀察自己運動後的疲勞，設計恢復訓練並記錄身體的反應；規劃改善讀書坐姿的課程，記錄一段時間後的變化 |
| 護理 | 觀察照護人員怎麼在緊湊的時間裡照護病人；把生物課學到的知識用在自己身上，記錄並評估自己的身心狀況 |
| 醫學檢驗 | 把實驗報告寫得清楚有條理，再對照報告後的回饋，看哪裡能改進 |
| 影像放射 | 找放射線的科普知識，用它來設想問題。例如想觀察特定細胞的變化，該用哪種放射線方式 |
| 藥學 | 訪談藥學系畢業的學長姐，了解大學學什麼、現在的工作要哪些技能 |
| 語療聽力 | 透過校內、網路資源或基金會接觸聽語失能族群，了解他們的限制與困境 |
| 獸醫 | 留意人畜共通疾病的資訊，了解人類疾病的起源和傳播與動物的關係 |
