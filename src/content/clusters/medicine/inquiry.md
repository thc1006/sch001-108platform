# 醫藥衛生學群自主學習與探究專題方向

這一頁為醫藥衛生學群申請者提供「自主學習計畫」與「探究專題」的選題方向、規劃方法與呈現策略。

## 一、為什麼自主學習對醫衛學群特別重要

108 課綱賦予高中生「彈性學習時間」進行自主學習。對醫衛學群申請者而言，自主學習計畫與成果的重要性高於一般學群——因為 **幾乎所有醫學系都將高中自主學習計畫與成果納入參採**，服務學習與社團經驗也因符合醫衛人格特質而被多校重視。

更深層的原因是：醫衛專業的養成，本質上是一場長達數十年的「終身自主學習」。醫學知識快速更迭、藥物資訊不斷翻新——這正是藥學教育從四年制走向六年制的根本理由。教授透過你的自主學習計畫，評估的不只是「你學了什麼」，更是「你是否具備主動學習、自我規劃、持續探究的能力與習慣」。ColleGo! 將「主動學習」「主動積極」明列為本學群的核心能力與性格特質。

## 二、選題的三大原則

### 原則一：題目「貼近生活」勝過「艱深炫技」

一個常見的誤區是：認為自主學習題目必須夠專業、夠創新、夠艱深，才能展現實力。事實恰恰相反。升學輔導資源與各校範例都指出，**自主學習的主題不必過於專業或創新；簡單而貼近生活的主題，同樣能展現學習熱情與能力。**

對高中生而言，「掉書袋」式地堆砌艱深醫學名詞，反而暴露你只是抄資料、缺乏真實理解。教授尋找的是「學習潛力」，不是「現成的專家」。一個從生活觀察出發、紮實執行、誠實反思的小題目，遠勝過一個好高騖遠、虎頭蛇尾的大題目。

### 原則二：題目要與「核心動機」連貫

你的自主學習主題，最好能與整份學習歷程的核心敘事呼應。如果你的核心動機是「關注高齡照護」，那麼自主學習做「社區長者衛教需求調查」就比做一個無關的物理實驗更有說服力——它讓教授看見一個「想法一致、行動連貫」的人。

### 原則三：重視「歷程」勝過「完美成果」

教授對你「如何思考」「如何面對困難」的興趣，遠大於一個看似完美的最終成果。一份誠實記錄研究限制、方法修正、甚至失敗的報告，只要附上深刻的歷程反思，反而能展現學術韌性與誠實品格。**不要為了好看而粉飾——真實的探究歷程，本身就是最好的素材。**

## 三、醫衛學群自主學習／探究專題的選題方向庫

以下依不同興趣方向，提供可操作的選題靈感。這些都是高中生可實際執行的範圍，且能對應醫衛各學類的核心關注。

### 方向一：生命科學與基礎醫學探究

- 影響特定生理現象的因素探究（如：不同因素對心率、反應時間、睡眠品質的影響——可用穿戴裝置或簡單實驗收集資料）。
- 微生物與衛生主題：洗手方式、環境清潔對細菌量的影響（可用簡易培養觀察）。
- 藥用植物／中草藥的科學探討（適合對中醫、藥學有興趣者）。
- 探究與實作課程的延伸：把課堂的探究題目做更深入的後續研究。

> **提醒：** 涉及人體實驗者，務必符合研究倫理——不得有侵入性、不得造成傷害、需受試者知情同意。這份「倫理意識」本身就是醫衛專業素養的展現。

### 方向二：公共衛生與健康議題調查

- 校園或社區的健康行為調查（如：同學的飲食習慣、睡眠時數、視力保健、3C 使用與健康）。
- 健康識能（Health Literacy）主題：民眾對某疾病、疫苗、用藥的認知調查。
- 流行病學概念的入門應用：用公開資料分析某疾病的趨勢、地理分布。
- 健康不平等議題：醫療資源的城鄉差距、偏鄉醫療現況的文獻整理與反思。
- 後疫情公共衛生省思：傳染病防治、疫情監測、健康政策的探討。

### 方向三：醫療人文、倫理與社會議題

- 醫病關係、醫療溝通的探討（可結合志工觀察）。
- 醫療倫理兩難議題的研究：安寧療護、預立醫療決定、器官捐贈、醫療資源分配。
- 高齡社會與長照議題：長照 2.0 政策、失智照護、長者生活品質。
- 心理健康議題：青少年壓力、心理健康識能、身心症。
- 健保制度的永續性探討（此題與 MMI 面試常考議題高度相關）。

### 方向四：對應特定科系的探索型專題

| 科系 | 可操作的探究方向 |
|---|---|
| 牙醫 | 結合手作與美學的探索（素描、雕刻練習歷程），口腔衛生教育主題 |
| 物治／職治 | 復健原理的認識、輔具設計觀察、運動傷害預防、職業傷害的人因工程探討 |
| 聽語 | 語言發展、聽力保健、長者溝通障礙的議題探討 |
| 營養 | 飲食與健康的關聯探究、食品標示分析、特定族群（運動員、長者、慢性病患）的營養需求整理 |
| 醫檢／放射 | 檢驗原理或醫學影像技術的科普整理、實驗的精確度與誤差探討 |
| 護理 | 照護需求調查、護理人力議題、健康促進活動的設計與執行 |

## 四、自主學習計畫的撰寫架構

各校自主學習網站與計畫範本通常包含以下要素，撰寫時建議涵蓋：

1. **計畫名稱與主題簡介：** 一句話說清楚你要探究什麼。
2. **學習動機：** 為什麼選這個題目？它如何與你的興趣、未來科系連結？（動機要真實、具體）
3. **學習目標：** 你希望透過這個計畫，獲得什麼知識或能力？
4. **學習方法與資源：** 你打算怎麼做？（文獻閱讀、實驗、調查、訪談、線上課程⋯⋯）用什麼資源？
5. **預定進度：** 把整個計畫拆解成階段性的時程。
6. **預期成果：** 最後會產出什麼？（報告、海報、簡報、影片、實作品⋯⋯）
7. **（執行後）成果與反思：** 完成後，記錄實際成果、遇到的困難、如何調整、學到什麼。

> 高級中等學校自主學習網與各校自主學習計畫頁面提供官方範例與資源，可作為格式參考。

## 五、呈現策略：把自主學習寫成「有說服力的成果」

招聯會規範下，課程學習成果最多 3 件、多元表現最多 10 件，自主學習成果可放在多元表現中。要讓自主學習成果發揮最大效力，掌握以下要點：

### 完整呈現「探究的歷程」

不要只給結論。展示你的思考軌跡：你最初的問題是什麼？過程中如何修正？遇到哪些限制？——這正是教授評估「學習潛力」的核心。

### 誠實面對限制與失敗

如果你的調查樣本太小、實驗結果不如預期、問卷設計有偏誤——請誠實寫出來，並說明你如何意識到問題、如何改進。一份「承認研究限制」的報告，比一份「假裝完美」的報告更專業、更可信。

### 連結到科系與未來

在反思的最後，把這次自主學習連結到你的科系選擇：「這次調查讓我發現⋯⋯，也讓我更確定／更想了解⋯⋯」。這展現了「探索 → 認知 → 動機」的完整鏈條。

### 善用「概念工具」但不要掉書袋

如果你在過程中用到了某個醫學或公衛概念（如「健康識能」「實證醫學」「初級預防」），要展現你是「用它來分析現象」，而不是「為了展示自己懂而硬塞」。理論是工具，不是裝飾。

## 六、自主學習的常見地雷

| 地雷 | 問題所在 | 修正方向 |
|---|---|---|
| 題目好高騖遠、超出能力範圍 | 虎頭蛇尾、無法完成，或淪為抄資料 | 選貼近生活、可實際執行的小題目 |
| 只給漂亮結論，藏起歷程 | 教授看不到你的思考與學習潛力 | 完整呈現探究歷程，含困難與修正 |
| 粉飾失敗、假裝完美 | 不真實，且浪費了最好的反思素材 | 誠實記錄限制與失敗，深刻反思 |
| 主題與核心動機脫節 | 整份檔案像散沙，無法說服教授 | 讓自主學習呼應你的核心關注 |
| 掉書袋、堆砌專業名詞 | 暴露缺乏真實理解 | 用簡單概念分析真實現象 |
| 計畫與成果都很空泛 | 無具體產出、無具體反思 | 一定要有具體產出（報告／作品）與具體反思 |

## 七、給申請者的行動建議

1. **從「你真正好奇的事」出發。** 最好的題目不是最炫的題目，而是你真心想知道答案的題目。
2. **小題目，深做。** 與其大而空，不如小而實。一個紮實完成的小調查，勝過一個半途而廢的大計畫。
3. **及早開始、留下紀錄。** 自主學習是長期歷程，過程中的筆記、修正、困難都要留存，它們是反思的原料。
4. **誠實是最高策略。** 承認限制與失敗，反而展現專業與成熟。
5. **讓它與整份檔案「對話」。** 自主學習應與你的服務經驗、科系動機、未來想望連成一條線。
