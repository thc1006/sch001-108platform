## 怎麼選題

- 從生活裡的問題開始。高中生做得完的小題目，比艱深的大題目好。題目裡塞滿醫學名詞，反而看得出只是抄資料。
- 和你想讀的系連在一起。例如你關心長者照護，做社區長者的衛教需求調查，就比做一個無關的實驗更能說明你的動機。
- 留下過程。問題怎麼來、方法怎麼改、遇到什麼限制，都記下來，這些是之後寫反思的材料。

## 題目方向

下面是高中生做得到的例子，可以照自己的興趣改：

| 方向 | 題目例子 |
|---|---|
| 生理與基礎醫學 | 睡眠、運動對心率、反應時間的影響；平常有喝含咖啡因飲料和沒喝的同學比較；洗手方式和手上細菌量的關係（培養皿要在老師指導下培養和銷毀）；藥用植物的科學資料整理 |
| 公共衛生 | 同學的睡眠時數與 3C 使用調查；民眾對某種疾病、疫苗或用藥的認識（健康識能）；用政府公開資料看某種疾病的趨勢和地區分布；城鄉醫療資源的差距 |
| 醫療人文與社會 | 醫病溝通的觀察（可以結合志工經驗）；安寧療護、預立醫療決定、器官捐贈的資料整理與反思；長照 2.0 和失智照護；青少年的壓力與心理健康 |
| 對應特定科系 | 牙醫：素描、雕刻的練習紀錄，口腔衛生衛教；物治、職治：輔具觀察、運動傷害預防；聽語：長者的溝通困難；營養：食品標示分析、特定族群的營養需求；護理：設計並執行一次健康促進活動 |

涉及人體實驗者，務必符合研究倫理：不得有侵入性、不得造成傷害、需受試者知情同意。不要讓受試者吃或喝任何東西。做問卷或訪談也一樣，先說明目的，讓對方知道可以不回答、可以隨時停止，資料不要寫出可以認出是誰的資訊。研究方法的細節可以看〈[研究方法工具箱](../../../autonomous-learning/methodology.html)〉。

## 計畫與成果怎麼寫

「高中自主學習計畫與成果」是多元表現的一個項目，醫衛校系採不採計，要查各校系當年度的分則與準備指引。臺大醫學系 115 學年度的準備指引就採計這一項，要考生「具體說明自主學習計畫之收穫與反思」。

自主學習計畫沒有規定的格式，寫清楚學習主題、目標、內容、時數和方法就可以，格式可以參考〈[計畫範本庫](../../../autonomous-learning/plan-templates.html)〉。親子天下的整理引國立大學教師的說法：大學端並不期待高中生交出多艱深、多學術性的自主學習報告，能呈現對問題的敏感度、洞察力和解決問題的能力，就是教授最有興趣的。

成果不完美也可以寫。台大園藝系和台北大學社會系的教授都說過，失敗的過程也可以記錄；作品普通，但交代了方法、看出哪裡不足、說明下次怎麼改，就是完整的自主學習歷程。樣本太小、實驗結果不如預期、問卷題目有偏誤，都照實寫出來，再寫你怎麼發現、怎麼改。

寫反思時，最後可以連回你想讀的系：「這次調查讓我發現……，也讓我更想了解……」。

國教署 108 課綱資訊網的自主學習專區，收錄了各校的自主學習成果範例。

## ColleGo! 建議的學類體驗

ColleGo! 每個學類頁的「學類體驗」，列了高中生可以做的活動：

| 學類 | ColleGo! 建議的體驗 |
|---|---|
| 醫學 | 訪問醫學生或醫師，了解各階段在做什麼、碰到什麼問題，評估自己適不適合 |
| 公共衛生 | 觀察一個疾病傳播的新聞事件，看預防措施是否有效，記錄疾病的變化和預防方式 |
| 牙醫 | 以特定模型為範本練習雕刻；學習和年長病患溝通 |
| 物理治療 | 加入運動團隊，了解骨骼肌肉的作動和運動傷害；從陪病、就診或醫療志工觀摩醫病互動，記下和原先想法的差異 |
| 職能治療 | 觀察自己運動後的疲勞，設計恢復訓練並記錄身體的反應；規劃改善讀書坐姿的課程，記錄一段時間後的變化 |
| 護理 | 觀察照護人員怎麼在緊湊的時間裡照護病人；把生物課學到的知識用在自己身上，記錄並評估自己的身心狀況 |
| 醫學檢驗 | 把實驗報告寫得清楚有條理，再對照報告後的回饋，看哪裡能改進 |
| 影像放射 | 找放射線的科普知識，用它來設想問題。例如想觀察特定細胞的變化，該用哪種放射線方式 |
| 藥學 | 訪談藥學系畢業的學長姐，了解大學學什麼、現在的工作要哪些技能 |
| 語療聽力 | 透過校內、網路資源或基金會接觸聽語失能族群，了解他們的限制與困境 |
| 獸醫 | 留意人畜共通疾病的資訊，了解人類疾病的起源和傳播與動物的關係 |
