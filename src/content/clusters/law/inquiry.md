一份法政專題，從一個有爭議的問題出發，查資料、比較正反兩方的理由、寫出你的判斷，最後回頭檢討。抄法條或整理新聞，算不上專題。做完的專題可以當課程學習成果，也是自述和面試好講的素材。

## 做專題的四個步驟

1. 找爭點：從生活、新聞或課堂裡，找一個兩邊都有道理的問題，例如「學校可以搜查學生的書包嗎？」「政府該怎麼管假訊息，又不侵害言論自由？」。答案一看就知道的題目，做不出東西。
2. 查資料：找相關的法條、判決、政府資料、學術文章和可信的新聞，記下出處，也判斷每份資料可不可信。
3. 比較正反兩方：把支持和反對的理由都寫出來，再說明你的判斷和依據。法政專題和一般心得的差別就在這一步。
4. 檢討：寫下結論還有哪些地方站不住、哪些問題沒解決、你的看法在過程中怎麼改變。

題目可大可小，重點是四步都做到、資料查得仔細，結論對不對反而其次。選你真的在意的議題，比選看起來厲害的題目容易做下去。

## 三個方向的題目例子

| 方向 | 題目例子 | 對應的科系 |
| :--- | :--- | :--- |
| 法律 | 分析一則有爭議的判決，整理爭點和法官的推理；研究一次修法（例如個資、性平相關的法律）對生活的影響；比較不同國家怎麼處理 AI 生成內容的著作權 | 法律、財經法律 |
| 政治、國際關係 | 研究一次選舉的制度和投票結果；整理一場國際爭端裡各國的立場；比較兩個國家民主化的過程 | 政治、外交 |
| 公共行政、政策 | 調查社區的一個公共問題，例如交通、長照資源、垃圾處理，訪問相關的人，提出可行的改善方案 | 公共行政、行政管理 |

判決分析的重點放在法官怎麼推理、怎麼在不同的價值之間取捨。公共行政的社區調查，要實際去現場、找人訪問，比只讀資料更能看出你願意動手。

## 研究方法

不用寫成學術論文，用上一兩種方法，專題就更有說服力：

- 文獻和文本分析：有系統地讀法條、判決、政策文件和文章，整理出各方的爭點。判決可以在司法院的裁判書查詢系統用關鍵字找。
- 問卷和訪談：想知道大家怎麼想，可以做一份小問卷，或訪問幾位相關的人。報告裡要寫清楚你問了誰、問了幾個人，結果只能代表這些人。
- 個案比較：挑兩個可以對照的例子，例如兩則判決、兩國的制度、兩個縣市的政策，比較哪裡相同、哪裡不同、為什麼。
- 公開資料：用政府資料開放平臺、中選會選舉資料庫的資料（例如選舉結果、預算、統計），做簡單的統計和圖表。想讀公行系的特別適合，政大公行系就要修統計學。

## 記錄和資源

- 先寫一份簡單的計畫：想釐清什麼問題、要交出什麼成果、每週做什麼。
- 過程中把查過的資料和出處、每次的想法和修正都記下來，用部落格、共用文件或筆記本都可以。這份紀錄本身就能當成果交。
- 入門可以讀法律白話文運動的文章，它用白話寫真實的法律議題；再往下可以讀下面的書單。
- 做完以後，可以把同一個議題延伸到時事短評、模擬法庭、模聯或公民行動方案，自述就能講成一條線：因為關心所以去查，查了以後去做，做了以後看到更深的問題。

## 從學類體驗找題目

ColleGo! 每個學類頁都有「學類體驗」，列出高中生可以先做的事。下表摘錄其中可以延伸成專題的項目：

| 學類 | ColleGo! 建議的體驗（摘錄） |
| :--- | :--- |
| 法律 | 觀察法律條文的設計怎麼解決社會問題，例如勞動基準法能解決哪些問題、哪些還有待努力；關注社會新聞，研究事件的來龍去脈 |
| 財經法律 | 留意內線交易、企業併購、公平會審核、國際貿易這類商業新聞；到法院旁聽，記錄不同身分的人提出的訴求和立場，比較各方的利益與弱點 |
| 政治 | 閱讀報章雜誌的時事評論，判斷評論者的立場和評論之間的關係 |
| 行政管理 | 分析一項政府政策的優勢、劣勢和對眾人的影響；觀察民眾的需求，在政府網站寫下建議和可行的執行辦法；用公文的格式寫你關心的事 |
| 犯罪防治 | 讀心理學、社會學的書；讀刑事司法相關的作品，例如漫畫《家栽之人》，以及《風險社會》、《八尺門的辯護人》；學好機率與統計 |
| 土地資產 | 蒐集有興趣或有爭議的土地議題，記下問題點再找資料；找史料和過去的規劃圖，了解自己的生活地區當初怎麼被規劃、後來變成什麼樣子 |

## 計畫的格式

親子天下整理自主學習的文章寫，自主學習計畫沒有規定的格式，架構能清楚展現學習主題、學習目標、學習內容、學習時數、學習方法就可以。主題沒有想法時，可以參照志願校系的備審指引找方向。

## 入門書單

拉課力一篇書單的作者，把自己讀政治系時接觸到的書推薦給正在選系、或不知道自主學習要做什麼的高中生：

- 《台灣經濟四百年》：台大經濟系名譽教授寫的台灣經濟史，從 1624 年荷蘭人佔領台灣講起，可以連結歷史課的贌社、縱貫鐵路、肥料換穀、美援。
- 《獨裁者的進化：收編、分化、假民主》：用報導散文寫獨裁國家的現況與披著民主外皮的「假民主」。
- 《靈魂不歸法律管：給現代公民的第一堂法律思辯課》：台大法學院名譽教授寫的法律入門書，從生活化的角度切入法律概念。
- 《真相製造》：台灣記者到比利時、法國、印尼、德國、中國與台灣採訪，寫假新聞與社群媒體的政治操作。

作者也寫，自己原本以為自己對法律有興趣，讀了書、參加營隊、在大學上過法律課以後，才發現自己對政治和新聞更有興趣。
