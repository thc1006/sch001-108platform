ColleGo! 列的法政學群多元能力是語文理解與表達、批判思考、邏輯推理、問題解決、說服協商、主動學習，性格特質是主動積極、深思力行、合作互助。

## 六個學類看重什麼

下表是 ColleGo! 各學類頁最看重的前三名，越前面越看重。

| 學類 | 高中課程領域 | 多元能力 | 性格特質 |
| :--- | :--- | :--- | :--- |
| 法律 | 國語文、公民與社會、英語文 | 語文理解與表達、邏輯推理、批判思考 | 主動積極、堅毅負責、深思力行 |
| 財經法律 | 國語文、公民與社會、英語文 | 邏輯推理、語文理解與表達，第三名並列：說服協商、問題解決 | 主動積極、自信肯定、深思力行 |
| 政治 | 英語文、公民與社會、國語文 | 語文理解與表達、批判思考、邏輯推理 | 主動積極、變通開創，第三名並列：合作互助、深思力行 |
| 行政管理 | 公民與社會、國語文、英語文 | 批判思考、問題解決、主動學習 | 主動積極、樂群敬業、合作互助 |
| 犯罪防治 | 公民與社會，第二名並列：國語文、英語文 | 批判思考，第二名並列：社會覺察與合作、說服協商、問題解決 | 第一名並列：主動積極、堅毅負責；第三名並列：探究冒險、自信肯定、親和接納 |
| 土地資產 | 國語文、公民與社會、地理 | 語文理解與表達、問題解決、主動學習 | 主動積極、合作互助、深思力行 |

六個學類的性格特質，第一名都是主動積極。政治學類的英語文排第一，加深加廣課程的前四名有英文閱讀與寫作、英語聽講兩門。ColleGo! 的政治學類體驗也建議加強英文，理由是台灣的政治學研究多半師承歐美；另建議增加第二外語能力，提升國際研究的深度與廣度。

單看一個系，政大法律系在 ColleGo! 列的性格特質第一名是主動積極，接著是並列的堅毅負責、深思力行、自信肯定。

## 台大法律系寫的能力

台大法律系 115 學年度的書面資料準備指引，在「其他」一段寫，要具備「問題之分析與解決」「資料之閱讀與批判」「口語表達與聆聽」的能力，具有「社會關懷與服務人群」及「國際視野」。自述的寫法詳見〈申請備審與面試要點〉。

## 高中可以做的準備

政大法律系在 ColleGo! 的學系頁建議高中生主動閱讀相關書籍及蒐集資料，「自主學習及長期閱讀是必須的」；也提到英文能力，因為法遵工作要熟知國際法規，閱讀英文文獻是必要能力。

ColleGo! 法律學類頁另外寫，對數學、物理等基礎自然科學有興趣的人，「將來不僅較能理解法律之邏輯思維」，也較容易具備法律專業需要的其他專業能力。

## 要處理反方論點

法政的議題常常是兩種正當的價值互相衝突，例如言論自由和名譽保護、公共利益和個人權利。只有立場、說不出理由，在法政系讀起來就不夠。

寫專題或自述時，先分清楚哪些是事實、哪些是價值判斷，把對立的觀點公平地寫出來，再講你的判斷。讀的人看到一個強烈的主張，第一個想問的就是「他想過反對的意見嗎？」主動處理反方，比一面倒的說法有說服力。能誠實寫出「我原本支持 A，讀了反方的論點以後改成 B」，也看得出你會修正自己的想法。

口才好不等於論證好。說話流暢、氣勢強，比不上理由清楚、回應得了反方。

## 每項能力在備審裡怎麼呈現

| 能力或特質 | 可以拿出來的東西 |
| :--- | :--- |
| 邏輯論證 | 議論文、議題探究報告裡的正反論證；辯論的賽後檢討，寫你的論點為什麼說服了人或被駁倒 |
| 語文表達 | 結構清楚、沒有錯字的自述和報告；法政系靠文字說理，文字本身就是證據 |
| 英文 | 英文檢定成績；讀英文文章或外國判決寫的摘要；政治、外交、法律都看重英文 |
| 公共關懷 | 說得出一個具體議題：讀了什麼、想了什麼、做了什麼。例如關心個資保護，就寫你查過哪些法條和新聞，比寫「我關心人權」具體 |
| 主動積極 | 自己發起的探究、倡議或自主學習計畫，寫你怎麼發現問題、怎麼開始做 |
| 合作 | 模聯、模擬法庭、公民行動方案裡你負責的部分，用具體的動詞寫，例如「負責整理三則判決的爭點」 |
