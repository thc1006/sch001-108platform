# 🔬 FlexSearch POC 測試指南

## 📋 測試目標

驗證 FlexSearch + segmentit 的：
1. 中文分詞效果
2. 搜尋速度 vs Fuse.js
3. 搜尋準確度
4. 整體可行性

---

## 🚀 如何開始測試

### 步驟 1: 開啟測試頁面

直接在瀏覽器中開啟 `poc-flexsearch.html`

### 步驟 2: 等待索引建立

觀察「索引狀態」面板：
- 🔵 **準備中...** → 正在載入
- 🟢 **✅ 已就緒** → 可以測試
- 🔴 **❌ 載入失敗** → 檢查檔案路徑

---

## 🧪 關鍵測試案例

### 測試 1: 中文部分詞搜尋 🔥 (最重要)

**查詢**: 「科學」

**預期**:
- ✅ FlexSearch: 找到「科學展覽」、「科學研究」等
- ❌ Fuse.js: 可能只找到完全匹配「科學」的結果

**這是 FlexSearch 的核心優勢！**

### 測試 2: 完整 Benchmark

點擊「🔥 完整 Benchmark」按鈕

**預期結果**:
- 總平均速度提升: **5-15x**
- FlexSearch 平均: 2-5ms
- Fuse.js 平均: 20-50ms

---

## ✅ 決策標準

### 建議遷移
- [x] 平均速度提升 > 2x
- [x] 中文部分詞搜尋有效
- [x] 無明顯功能缺陷

### 不建議遷移
- [ ] 速度更慢
- [ ] 結果準確度大幅下降
